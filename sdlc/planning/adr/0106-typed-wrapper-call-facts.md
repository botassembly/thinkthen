# ADR 0106: Owned facts on Go and PHP typed calls

- Status: Accepted after fresh High design/API review at `92cb4112` and coordinator approval on main `b6f06c4fc`. Ian can overturn the return-shape choice before 0.1.
- Date: 2026-09-29

## Context

Ian's [every-surface facts ruling](../../issues/2026-09-26-every-surface-should-give-back-run-facts.md) requires library judgment calls to return facts on every call, without a setting or second call. The C door now provides owned `*_with_facts_opts` outputs for decide, decide-many, recognize and relate. [ADR 0101](0101-typed-c-call-facts.md) preserves the old bare **C exports** for compiled ABI compatibility; it does not exempt newer Go/PHP wrapper methods. Current Go `Engine.Decide`, `DecideMany`, `Recognize`, `Relate` and PHP `decide`, `decideMany`, `recognize`, `relate` still call those old exports. Their JSON `Call`/`call` routes already return a `value`/`facts` envelope, and their started-failure paths already copy facts. These wrappers are pre-0.1; retaining bare typed spellings would silently perpetuate the gap.

## Decision

Migrate the four public typed methods in **each** wrapper in place. Do not add bare-success aliases, a setting, a second request, a process-total substitute, or a mutable last-success accessor. A successful typed call returns its previous value and its **own final** facts from the same existing C `*_with_facts_opts` invocation. The method names and arguments stay; their return shapes change before 0.1. `Call`/`call` continue to return their existing JSON envelope string for the ten-verb JSON grammar, and `usage` remains a separate process-total route. Go and PHP have no direct typed choose/tag/score/filter/rank/find/annotate methods; those verbs already use `Call`/`call` and are not rewritten here.

| Method | Go success | PHP success |
| --- | --- | --- |
| `Decide` / `decide` | `Result[Answer]{Value: Answer, Facts: Facts}` | `['value' => ['outcome' => int, 'probability' => float], 'facts' => array]` |
| `DecideMany` / `decideMany` | `Result[[]Answer]` | `['value' => list<answer>, 'facts' => array]` |
| `Recognize` / `recognize` | `Result[string]`, preserving the existing result JSON bytes | `['value' => result JSON string, 'facts' => array]` |
| `Relate` / `relate` | `Result[string]`, preserving the existing result JSON bytes | `['value' => result JSON string, 'facts' => array]` |

In Go, `Result[T]` has public `Value T` and `Facts Facts`. `Facts` decodes the C facts JSON into required unsigned `Records`, `RequestsSent`, `CacheAnswers` and `Seconds float64`, with optional `InputTokens *uint64`, `OutputTokens *uint64`, and `Model *string` (JSON names remain the C names, and optional fields omit absent keys when encoded). Validate presence and types of the required keys rather than accepting Go's zero values for missing keys. Optional pointers are nil when keys are absent; do not turn unreported tokens into zero. Result values and optional-field storage are Go-owned before C strings are freed and before `Engine.Close`. A successful native return with malformed facts is a wrapper error, never a factless success. The existing `Error.Facts` copied `json.RawMessage` stays for started failures; a caller may decode it as `Facts` if desired.

In PHP, keep the current answer arrays and result JSON strings as the nested `value`. Decode the independent owned C facts string to an associative array; absent optional fields remain absent keys. Copy both native strings using their returned byte lengths and free each exactly once with `thinkthen_free_string` in `finally`, including if the other copy or JSON decoding fails. PHP FFI receives both outputs through pointer slots so it retains the pointers needed to free them. No `FFI\CData` or borrowed success pointer escapes. The existing `ThinkThenFailure::factsJson` remains a copied nullable string for a started failure.

`DecideMany`/`decideMany` must invoke the facts-returning C symbol even for zero texts, with required facts pointer/length slots: success has an empty value, `facts.records=0`, zero sends and no fabricated token/model values. Bulk facts arrive only after the batch finishes or stops and joins. On a nonzero C return, publish no value or success facts; read the existing same-thread failure slot immediately. Pre-start Usage, invalid input and locally refused calls have no facts. A started backend, deadline or cancellation failure retains the native final facts in Go `Error.Facts` or PHP `ThinkThenFailure::factsJson`. Wrapper allocation/copy/parse errors do not pretend to be native started failures.

Go retains `runtime.LockOSThread` around each native call and its borrowed failure reads. Successful result/facts buffers are call-owned, copied and independently freed before releasing the engine read lock. Concurrent calls on one engine cannot overwrite each other's success facts; `Close` still waits for in-flight calls. PHP keeps its documented single-threaded FFI limitation and does not claim PHP-driven concurrent calls; sequential calls on one engine, a later failure and engine close cannot change a returned array/string. The underlying C same-engine two-caller proof remains relevant but is not PHP concurrency proof.

## Compatibility and limits

This deliberately breaks pre-0.1 typed caller expressions: Go `answer.Outcome` becomes `result.Value.Outcome`, bulk indexing becomes `result.Value[i]`, and recognize/relate string use becomes `result.Value`. PHP `$door->decide(...)['outcome']` becomes `['value']['outcome']`, bulk `array_column($rows, ...)` becomes `array_column($result['value'], ...)`, and string operations on typed recognize/relate use `['value']`. Update source examples, tests, direct and installed consumers in the same implementation. Keep the old C symbols solely under ADR 0101's ABI exception; do not describe Go/PHP methods as legacy or keep bare wrappers under new names. A published module/tag or external consumer is not silently migrated; packaging and release qualification must use matching new wrapper source and a C archive that exports the facts symbols.

The C facts object has `records`, `requests_sent`, `cache_answers`, `seconds`, optional tokens and model. It contains no cost, request ID, server time, full probabilities, request digests or per-row detail. This ADR fulfills the owned **call-facts carrier** for these typed methods; the broader issue's timing, price, detail and other-surface criteria remain open. It changes no scheduler, C ABI, JSON schema, SQL/DataFrame host or CLI behavior. ADR 0105 remains reserved for held SQL/DataFrame work.

## Proof required before implementation landing

Use current matching C header/library and the existing loopback fixtures. In each wrapper, pin one successful scalar, nonempty ordered bulk, recognize and relate value **and** facts; one empty bulk with `records=0` and no send; a reply without usage with absent optional token fields; pre-start failure with no facts; started failure with copied final facts that survives a later call and close. Inspect each wrapper route for exactly one native operation and count requests outside the wrapper to corroborate no second provider call. Go also pins two overlapping calls on one engine with distinct owned facts; PHP pins sequential lifetime and retains its concurrency limitation. Reuse the existing mixed-answer order and C owned-facts fixture, not a second body corpus. Source proof, a matched installed Go/PHP+C package consumer, and actual runner/release qualification are separate receipts; a former installed archive lacking these C exports is not evidence for this API.
