Rules for both agents:

1. **Claim before you start.** Edit your lane's row on main in a one-line commit, run lint, and push. Name the ticket and the files it opens.
2. **Never start work whose files another lane holds.** A shared page such as `specification/settings.md` or `CHANGELOG.md` is not held; the second lander merges it. `sdlc/ratchet.json` is measured again after each merge, never kept by hand.
3. **Land your own work.** Merge `origin/main`, measure the ratchet, run the four rungs, push to main, then clear your row. Every heavy rung takes the shared heavy lock, so the lanes take turns.
4. **Update "Every item" in the same landing commit.** Set each settled item's status. A non-issue carries its evidence in the commit, and its repo issue file moves to `sdlc/issues/closed/`.
5. **Review with your own vendor.** Codex tickets get fresh Codex reviewers. Claude tickets get fresh Claude reviewers. The owning agent accepts its own tickets.
6. **Claude is the queue owner.** Only Claude opens a new lane for either agent, and it marks a new lane here before Ian starts it. When a Claude lane clears, Claude writes the freed component or batch into Codex's "Next in this lane" cell.
