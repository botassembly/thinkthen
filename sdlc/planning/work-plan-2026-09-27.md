1. **Claim before you start.** Edit your lane's row on main in a one-line commit, run lint, and push. Name the ticket and the files it opens.

4. **Update "Every item" in the same landing commit.** Set each settled item's status. A non-issue carries its evidence in the commit, and its repo issue file moves to `sdlc/issues/closed/`.
