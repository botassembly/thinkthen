# Add a C++ binding

Filed 2026-09-28 by the marketing lead, on Ian's instruction: "I definitely want to support C++. I'm going to have the team work on that as well." Ian ranks C++ ahead of COBOL.

## What marketing sees

The deck and site list 24 bindings from one shared list: Ada, Bash, C, C#, COBOL, Dart, DuckDB, Go, Java, Kotlin, Objective-C, pandas, PHP, Polars, PostgreSQL, Python, R, Ruby, Rust, Scala, SQLite, Swift, TypeScript and Zig. C++ is not among them. The earlier talking points named C++ as a C-header consumer. No experiment or ticket proves it.

## What marketing needs

A C++ binding proven the way the other language ports were proven: a typed layer over the C door, with the same contract checks. Once it lands, marketing adds C++ to the shared binding list in the deck, and the count on the slide updates itself.
