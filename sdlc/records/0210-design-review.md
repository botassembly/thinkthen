## Response to the first design review

The first draft used an early URL check and a second send-time key read. The reviewer found that a changed environment could make those values differ after the URL was hashed or a recording folder was touched; replay would never call the second reader. The corrected proposal snapshots one optional effective CLI key after final URL resolution, checks it before any URL-derived digest, output or folder access, and makes both production `KeyReader` closures return that same snapshot. Public builders check their final captured or explicit override key at `build`. An absent key stays optional for dry-run and replay. This changes the CLI's key-read timing, not safe-request routing or identity.

The review also found that the proposed Ian choice needs to cover `specification/recording.md`'s replay, mismatch and temporary-write promises, the backends key-order text, CLI help and executable `specification/check.md`, not just the dry-run sentence. The ticket now lists these exact amendments and retained no-send, keyless and replay behavior. Its compact edge table names final endpoint host and suffix matches, multibyte exactness, percent-encoded nonmatch, explicit/captured/override keys, and raw and later `Debug`, including `Details` and recognition plan. The preflight names the source paths and records these omissions as preparation lessons. Ian later approved the choice at `a2c9057a`.

The follow-up reviewer found two remaining wording and inventory misses. `cli/status.rs::gather` calls `Environment::api_key_set`, a second `read(KEY_VAR)` in `cli/edge.rs`; the proposed status field now derives from the same checked snapshot as its URL. The ticket now limits its enforceable disclosure claim to the backend URL and URL-derived identities. Caller evidence, question, or model text may independently contain the same bytes and is outside this rule. No general content detector or runtime change is proposed here. The production key-reader search and these corrections are recorded in the preflight for final review.
