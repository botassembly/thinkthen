## What the build taught us

The missing `.git` failure starts before legacy part selection because `release-pack` read HEAD unconditionally. Moving that read under the wrapper branch repairs the generic route without touching any SQL package operation. A copied wrapper alone would leave the C/Rust source unverified; checking only archive members still misses an extra compiler configuration. The corrected comparison inventories both sides before `part_c` and rejects extra inputs without an exemption. The same Git tar gives a checked commit identifier and exact wrapper member bytes, so the later Go/C++ mode need not infer source from a caller's SHA text. A stand-in should capture observed arguments, leaving the fixture to assert them. Synthetic Cargo/Docker outputs cannot qualify C, manylinux or the runner.
