# 0282 Ada, Objective-C and COBOL typed call facts build

Date: 2026-09-29. Accepted design `e800984e`; this candidate follows main `0a32572d3` and the exact codex-7 source claim. ADR 0106's every-call ruling is the outcome; the C ABI and JSON doors remain unchanged. Old typed calls returned only their value, leaving no owned facts from the same operation.

## Changed behavior and ownership

- Ada's four typed procedures now return their former `Decision`, ordered `Decision_Array` or `JSON_Result` plus `Run_Facts`. The existing public `Call_Facts (JSON_Result)` accessor keeps its name and contract. Independent controlled owners finalize native structured output and facts on success, decode exception and failure. `Capture` copies borrowed started-failure data on the calling task before another native operation.
- Objective-C's four typed selectors and their counted `*Bytes` variants require `TTCallFacts *`; `tt_call_facts_clear` frees its independent owned model. Each route calls one existing C facts `_opts` export. Native structured value and facts are separately freed after host copies or on any failed decode/allocation. `capture` precedes further native work, and existing client/token join-before-close bounds remain.
- COBOL's sole typed `TT-DECIDE` now writes a bounded owned `tt-facts` group beside its former answer and failure group. It validates the counted JSON with the packaged `TTJSON.c` and narrow `tt_shape.c` helper before publishing success, frees the C facts pointer even on rejection, and clears success facts on failure. The source link and copied installed consumer include the already packaged parser/helper objects. Raw C calls in the matrix and the generic `TT-CALL` stay as they were.
- Required counters are unsigned integral and in host range; seconds are finite and nonnegative, including fractions. Optional usage and model are independent; absent and present-null are distinct. No partial value/facts pair is published. No new API setting, C ABI field, provider call, JSON grammar or parser framework was introduced.

## Limits and What the build taught us

The direct Ada no-usage/model combination is covered by the accepted C facts contract and its strict decoder's independent optional extraction, but no new Ada backend response fixture was added: its existing backend always supplies usage and is outside this claim. Objective-C and copied COBOL have explicit no-usage/model decoder witnesses. Source and copied installed tests do not qualify clean current-pin release archives, another OS/compiler, actual release runners or the remaining cost/detail criteria in the every-call issue. No full `lint`, `test`, `spec`, `surfaces`, package, provider, Actions, SQL/DataFrame or all-port campaign was run.

A packed replay is one cached **reply**, even when it finishes three records. A thread launch is not overlap evidence; two observed held arrivals before release are. The native C API returns two separately owned pointers, so host success and failure cleanup must track them independently. COBOL's former typed link line omitted its parser/helper objects; the typed facts validator makes those existing packaged objects required. The Ada empty-array elaboration order was a real pre-start boundary bug exposed by the new refusal witness. Host ratchets include fixture Python and headers as well as primary source, so all configured counters were measured rather than only the implementation language.
