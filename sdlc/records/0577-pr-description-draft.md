# Draft PR description for approval

ThinkThen puts Jev, TypeSafe's decision model, or any model like it in your SQL through ten functions, and works with Jev, OpenAI or a local model. Ask a typed question and get back `true`, `false`, a label or a number that your code can branch on; a model can say not sure, and a failed call never looks like an answer. ThinkThen packs many records into few requests, saves each answer for reuse, and lets tests replay saved answers with no key and no network. The extension is free and MIT licensed; hosted models charge per token, and local models are free to use on your own computer. This submission targets DuckDB 1.5.6 and 2.0.
