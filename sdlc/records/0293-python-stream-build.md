## What the build taught us

Moving Python input traversal to `__next__` preserved SQLite's calling-thread constraint without a Python-side polling scheduler. The initial SIGINT test expected zero completed records after an already admitted reply; core Batch records that completion before Stop turns the outcome into cancellation, so the correct retained receipt is records 1, requests 1. Stream `Drop` intentionally cancels without running Python cleanup on the worker. Clippy required splitting the worker and event reader into smaller paths, while the larger merged core Facts made the frame's owned failure enum worth boxing. Upcoming 0295/0296 must keep caller-thread input and final facts distinct from a partially consumed stream.
