## What the preparation taught us

The existing digest-pinned manylinux route supplies a real ARM64 compiler and stock DuckDB CLI on the M5 without installing a new host service or an unrelated Ubuntu stack. Its base image lacks Rust, but the release script's already pinned bootstrap and the repository's Rust version run in an isolated mount. The concrete source gap is wider than the package selector: the ARM64 release-container branch must stage verified C++ DuckDB inputs before the packer can stop using the old C API. Native ARM64 VM execution is useful pre-runner proof, but only the actual release runner can establish the final advertised runner result.
