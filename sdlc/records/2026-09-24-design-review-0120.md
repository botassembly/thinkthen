## Round 1 at `2f9482bc`: findings

1. The script changed `HOME` before it looked for the toolchain, so it could never pass. The scratch `HOME` hid `~/.cache/thinkthen-toolchains` and cargo's crate cache. Fix: read the real `HOME` first, or leave `HOME` alone.
2. The throttle tests shared one process, against the shared rule that puts each in its own. The held-arm test holds all 8 permits, so the other tests would flake. Fix: one test binary per throttle test.
3. The failed-marker test compared the door's output with the value the door itself used. Re-serializing a parsed member through a sorted map puts `cause` before `kind`. Fix: pin the literal marker, lift member text unchanged with `RawValue`, and take widened number and array text the same way.
4. Nothing said what choose, score, and tag over a Series do with a failed row. Fix: state the rule and test it.
5. The wrong-kind refusal had no sentence and no test, and `decide_series` cannot read a kind through the sealed `DecisionQuestion`. Fix: pin a sentence with a zero-request plant, and say decide relies on the engine's refusal.
6. The no-paid-backend plant could not turn red, because the next line overwrote the sentinel with the fake key. Fix: plant a change that lets the real key through.
7. R2-12's plant cannot be written in safe Rust, and R1-4's plant could stay green. Fix: fold R2-12 into R1-3, and give R1-4 a plant that changes type or metadata.
8. "Not run" was not tied to its one real cause. Fix: one probe step, `cargo fetch --locked --offline`, is the only failure that maps to "not run".
9. The README doctest would send requests and called three cache setters that override each other. Fix: `no_run` and one cache setter.

Confirmed: the answer that Python Polars does not need Rust Polars matches 0106. The trait signatures match 0084 and 0095, and `CallOptions<'_>` fits `decide_many_with` and `annotate_with`. The cancel departure is justified. The Evidence section passes `sdlc/scripts/tickets`. The five-method surface is the smallest that meets Ian's ruling.
