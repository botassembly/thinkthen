## Objective-C parser correction after High review

High review found that the public GNU Objective-C JSON tree rejected an escaped U+0000 even though `result.schema.json` permits it in entity text. The parser now carries decoded byte lengths for text and object keys. Key lookup, duplicate detection, and shape checks compare those lengths, so `"a\\u0000b"` remains three decoded bytes without truncating the raw JSON result. `checks/nul_text.m` exercises distinct and duplicate NUL-containing keys, then routes a schema-valid recognition result through the public `TTClient` boundary.
