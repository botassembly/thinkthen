# SQLite error-format Quick Fix

The accepted ADR 0105 section 8 format is now produced at SQLite's typed `Failure` boundary. Ordinary errors read `thinkthen <kind>: <message> (retryable: yes|no)`. Explicit removed-call and old-argument producers use `Failure::plain_usage` to keep their exact migration sentences. `Failure::value` still returns its safe structured JSON and the six SQLite result-code mappings are unchanged. This Quick Fix edits no shared core, C, Python, R, PostgreSQL, DuckDB or site source; its branch now includes the separately accepted core 0302 merge.

## What the build taught us

Preparation correctly identified `From<Failure> for rusqlite::Error` and the danger of deriving kind or retryability from a caller's prose. Its initial removal inventory missed the numeric legacy settings argument in `src/question.rs::call_settings`; source tracing found it, and the coordinator added that path to the claim. The first selected run also exposed `test_deadline.py` as a stale positional-API test: all three cases failed against the already accepted moved-into-settings behavior, regardless of the formatter. The refreshed preparation correctly called for a settings-based replacement. The new deadline fixture keeps the zero-budget, held-work and retry outcomes while separating retries from a short deadline and dropping a brittle 0.3-second timing claim. `test_settings.py` remains the single exact migration-sentence witness. The first preparation and build inventory scanned literal expected strings but missed `tests/conformance.py`'s parser, so its old optional retry marker made shared retryability checks inert. Future error-format preparation must inventory readers that parse or normalize output as well as assertions that compare it. The other affected test changes update only ordinary error text; plain removal expectations, values and request counts stay pinned.

The original SQL usability issue remains open for its other criteria and for full package and release qualification. This Quick Fix proves local SQLite formatting and selected host behavior only.
