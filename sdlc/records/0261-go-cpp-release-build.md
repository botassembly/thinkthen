## Fixture fixes and limits

The first pack attempt failed on sandboxed `sccache`; clearing Cargo's Rust compiler wrappers permitted the pinned offline build. A sandboxed Python backend could not open loopback (`PermissionError: Operation not permitted`), so the approved local-loopback run supplied the counted request proof. The first unrelated Go consumer had no VCS status, so `go build -buildvcs=false` made its local build deterministic. Its first `ldd` call omitted the selected loader environment and reported `libthinkthen.so.0 => not found`; passing that environment to `ldd` made the check inspect the same route as the executable. Reusing one Go build cache then retained a shared C link in the static build; a separate static cache produced the archive link witness. The C++ ABI helper initially had a closing-parenthesis syntax error; Python compilation and the focused rerun fixed it. The C++ second call initially hit the first mode's answer cache, so each mode now has its own cache path and counted request. Finally, Go's first installed byte comparison pointed both sides at the same unpacked files; copying native members into a separate prefix made the byte equality meaningful. These were fixture/setup failures, not C/engine changes. The final selector passes above followed each fix.
