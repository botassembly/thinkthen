## Boundary and proof

The new nested `src/ffi/typed_facts/ffi.rs` owns only the eight unsafe C exports and their shared pointer validation/publication path. It checks each scalar text length and the three bulk array extents with checked arithmetic against `isize::MAX` before raw slices, pointer addition or a send. It rejects null required output slots and every pair of exactly equal nonnull output-slot addresses, including both length slots and a nonnull zero-count array. It cannot inspect arbitrary invalid pointers or partial range overlaps; the caller still owns live, aligned, adequately sized, nonoverlapping buffers. `door.rs` takes `Call::facts` before scalar/recognition/relation conversion and terminal `Batch::facts` before the bulk count check. `failures.rs` retains a completed-facts slot outside the panic catch; ordinary postreply conversion failure and caught postcompletion panic record those facts in the existing thread/engine failure table. A panic before completion still has no facts. All fallible JSON/C-string work finishes before the final pointer writes. No result array element or string pointer is transferred on a nonzero code.

## What the build taught us

The finished facts were already present below the typed FFI door. A single `Option<Facts>` held by the guarded call can preserve them through a conversion defect without a mutable success slot or a second request. Bulk facts are available only after the batch reaches its terminal state; visible answers and actual sends differ under caching and recognition stages. The output-slot check must include a nonnull answer array even when count is zero, because the address can still equal a facts slot. Retained C examples now recommend the new forms while preserving their pinned output text. Existing Zig, Swift and Objective-C experiment binaries still link the old forms and are not silently upgraded. New target packages need rebuilt archives and export checks before they advertise these symbols; this Linux installed proof does not qualify macOS or ARM64 packages.
