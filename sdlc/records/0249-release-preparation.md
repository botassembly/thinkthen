These are source facts, not a CI result. The older [0128 preparation](0128-release-preparation.md) predates the current workflow and target routes.

The accepted 0249 build records already give local Linux package, ABI, loopback, public-corpus and installed-consumer proof at recorded pins. They do not supply a final-release-commit rebuild, release-runner outcome, checksummed GitHub asset or registry installation. The C wrapper is a separate native dependency for these packages.
