## What the build taught us

The active cap belongs at transport reservation, not merely at settings parse or engine construction. A process-wide count can coexist with distinct per-engine limit snapshots, including an unset engine that still contributes attempts. A second request of an already started call needs its own denial context; the existing first-send/retry distinction cannot describe it. The initial CLI later-send regression exposed that gap; the corrected public enum, exact CLI line and retained status-retry fixture now distinguish the contexts.

The Rust Polars door is `crates/thinkthen/src/public/frame.rs` plus `frame/` helpers; there is no `libraries/polars/src` or separate Polars ratchet. Nullable input is a request selection and result-placement concern. Preserving positions with a selection/restoration path lets the same engine and listener facts remain authoritative. A call-level probability should read the selected answer and its probability from one reply, not send a second request. Feature-on Clippy also catches problems hidden by default workspace checks, so the selected Polars target is necessary proof here.
