## What the build taught us

Fixed-width callers must distinguish primitive false, unresolved null and missing facts before dereferencing values. Independent packets preserve both answers and failures after their producing owners are gone. A private canonical packet projection proves shared semantics; it must not be described as direct typed runtime coverage of every generated field.

Archive checks must follow the current package contract when a source-only binding becomes native-bearing. Compare its bundled native bytes with the paired C artifact instead of preserving obsolete file names or treating package declarations as proof.
