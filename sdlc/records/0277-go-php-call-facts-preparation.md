## Practical design and proof handoff

Use ADR 0106's single result carrier on each direct typed method, preserving the old `Value` content. Go typed `Facts` keeps optional tokens/model nullable; PHP's associative facts array keeps omitted keys absent. Both copy owned C facts before native free and before a later call; native nonzero returns use current copied failure carriers. No extra network operation, new C symbol, scheduler, JSON schema or last-success state is needed. Pre-0.1 callers must update their field access and typed string handling. The product file/selector inventory and small outside-in proof are in the ticket; `fixtures/type_case.go` and `fixtures/type_case.php` use JSON `Call`/`call` and need no migration.

The current Go/PHP synthetic backends always add `usage` to successful replies, so a narrow missing-usage variant is needed to prove omission instead of substituting zero; reuse C's missing-usage expectation and existing host backend scripts rather than a new server. The old mixed-answer and portable five-text fixtures already prove order/body shape. New tests should inspect returned facts and independent listener request counts, not replay a second provider call. Source proof precedes a newly matched installed-package proof; actual runner and release claims remain separate. `libraries/go/thinkthen.go` is 393 nonblank lines; plan local reuse or one pure decoding extraction if measured Go source growth becomes substantial. The 0276 child-environment batch owns script sanitation; inspect checks but do not edit unrelated check scripts here.

## Preparation lesson and next batches

The C ABI exception is easy to overread: it preserves existing C binaries, while the wrappers are pre-0.1 source APIs whose bare return shapes can be migrated now. The C owned-facts paths already handle empty bulk and post-reply ownership, so the wrapper work is conversion, memory lifetime and caller migration, not another fact engine. Implementation found that a typed relate result for two input entities reports one logical relation question in `facts.records`; input entity count is not the facts record count. After this pair, the next two bounded candidates are C++/Dart and C#/JVM typed wrappers; their currently referenced old `_opts` symbols establish adjacency, but each needs its own host proof. Other wrappers and held SQL/DataFrame surfaces remain outside this preparation.
