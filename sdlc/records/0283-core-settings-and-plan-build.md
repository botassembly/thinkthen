## What the build taught us

The plan output is a disclosure of the first prepared body and a whole-input summary, so old first-record acceptance tests actively hid later invalid input. A packed two-record request followed by a singleton has distinct wire shapes; counting records or treating the singleton as a one-member packed body gives the wrong byte oracle. The C constructor's duplicate scanner could be removed once a shared pure reader validated before map conversion. The later separate SQL/frame crates cannot access a private core type, so the minimal public re-export and C builder validation bridge had to land with the inventory delta. The numeric Rust deadline rename also reaches the C door internally. The settings checker had mistaken build-only package helpers for product environment readers because newer packages use `checks`, `fixtures` and `Tests`; classifying source paths instead of environment names preserved real product coverage and the old negative plants. The next 0289 refresh must keep SendBudget selection per reservation distinct from a process-wide configuration authority across engines with different snapshots, and specify lower, raise, unset, mixed-engine and retry denial semantics without adding token admission here.
