## What the build taught us

A native streaming aggregate may carry answers before its final packet. Retain every chunk and failure prefix instead of treating the last packet as the whole answer. Preview conversion must use the same single-record interpretation as named calls.

Deleting an API also requires migrating the installed smoke and examples. Test the actual package entry point and typed fields; keep site ownership explicit rather than retain a second public API for stale examples.
