## Source and proof

- `EngineBuilder::profile_json` parses the same closed profile schema as the file setter. The last profile setter wins. A focused public test proved a later inline profile avoids a missing file and a later file restores its local read failure.
- One public `SendBudget` counts process live attempts. `CallOptions` carries it into `Cancel`; HTTP reserves after the final stop and timeout check, before the usage mark and transport. A failed usage mark refunds the reservation. The private first/retry errors become six-kind public errors with a typed denial marker and a fixed safe CLI mapping. The public loopback case proved zero-cap `BeforeFirstSend` with zero sends, 503 then `BeforeRetry { last_status: 503 }` after exactly one send, a later spent first send, and an unrelated 503 without the marker after raising the total. The two focused HTTP cases proved a deadline during a held width consumed zero budget or requests, and a deadline during retry backoff consumed only the first send with no retry. A focused unit case proved that an inherited count and inherited reset marker cannot block the child's first reservation; this is a state simulation, not an operating-system fork test.
- SQLite now registers model, timeout, retries, JSON profile, record and replay setters, plus trailing millisecond deadlines on warm, recognize and relate. Its worker carries the process budget and maps a typed denial to the established spent-total sentence. On the pinned SQLite 3.50 host, selected Python cases passed for settings and zero-deadline no-send, a 503 retry stopped at total one, an inline profile refusal before send, and record/replay with zero replay sends. The fixture had to clear a tiny valid profile before asserting relate's deadline; otherwise profile validation won earlier.
- PostgreSQL now samples its six GUC values on the backend thread into `Plan`, uses the caller's setting snapshot in its worker, and maps typed denial to its established spent-total sentence. Folder GUCs remain superuser-only; model, timeout, retries and JSON profile are user settings. The selected installed-package `sql_settings_and_retry_total` check passed on PostgreSQL 16.15. It covered a 503 at total one, model/timeout/retries, invalid and valid profile no-send refusals, cache off, recorded answer and strict replay miss, and a non-superuser folder-setting refusal after GUC registration. The selected run reported one passed, zero failed.
- Root core Clippy, SQLite Clippy and PostgreSQL Clippy passed with `-D warnings`. The current settings checker and its 10 planted/self-test cases passed after its PostgreSQL source path followed the GUC module extraction. Policy checked 189 resolved packages and accepted tables.
