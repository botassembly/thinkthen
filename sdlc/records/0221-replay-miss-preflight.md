# 0221 replay-miss source preflight

Read-only source at main `0685cfaa`. The local register is `experiments/284-issue-register/102-replay-miss-does-not-say-why.md`; the historical experiment's report 09 predates landed batching and stopped-run facts. No tests, builds, or paid calls ran for this design preparation.

| Path | Current behavior | Design consequence |
| --- | --- | --- |
| `engine/recorder.rs::{prepare_checked,replay_only}` | A missing strict replay entry returns `Error::ReplayMiss(name)`. `cli/failure/recording.rs::message` prints the entry filename and explains that its name covers interface, address, request. | Keep digest and strict no-send path. Recorder knows exact identity but not a command, row, group or stage. |
| `cli/failure/stopped.rs::report`; `cli/asking/batched.rs::{failed,split_answered}` | `Stopped` already names a record; `BatchFailed` names the full request range. A multi-record replay miss can trigger one eligible split; the first-half failure retains the original range because the original missing whole request remains relevant. | Do not add a duplicate “record N” to the inner cause. Treat the range as a shared request and inspect both whole and half digests before changing this path. |
| `cli/asking.rs`; `cli/schedule.rs` | One-document asks return the inner replay miss, while streaming asks acquire `Stopped` from the scheduler. A dynamic `choose --options` question may differ by record. | Use only a fixed verb/source label at the document boundary; retain the existing position for streams. No pointer or question text. |
| `cli/annotate.rs`, `cli/annotate_schedule.rs`, `engine/annotate_schedule.rs`, `core/question_set.rs::check_name` | The file has several named members, grouped by evidence pointer. A `Work` currently retains its row number but not a public group label; scheduler has group indices internally. Member names are restricted to lowercase ASCII letters, digits and underscores. | A row number alone does not identify the grouped request. Review accepted group ordinal/member count, carried with failed work; do not print user-controlled member names. |
| `cli/find.rs`; `engine/facade/{recognize,relate}.rs`; `cli/{recognize,relate}.rs` | `find` prepares one aggregate set then returns a bare replay miss from `engine.find`. Recognize executes request chunks in three stages: boundary, combined kind and edge, then relation. Relate prepares shared pair chunks. Both currently lose stage/chunk context as the error climbs. | Name the complete `find` set, never one unit. Fixed stage labels require producer provenance; kind and edge are not separate second-stage labels. A chunk ordinal needs a private producer carrier, not inference from CLI input or a digest. Do not infer a unique relation, entity, word or question from a shared request. |
