## Observed startup boundary

Each of the five normal **source** gates executes `python3` on an absolute `types.py` script path. The script's own directory is then ahead of the standard library for ordinary imports, regardless of the shell working directory. Neither the shell parent nor these entry lines explicitly imports stdlib `types`, sets `PYTHONWARNINGS`, or uses a safe-path flag. Current ambient site startup can preload the stdlib module and make a prior green gate insensitive to this defect. A bounded direct-entry diagnostic used `/usr/bin/python3 -S` with only `PATH=/usr/bin:/bin`, `HOME=/tmp`, `PYTHONNOUSERSITE=1` and **no preimport or runpy**. All five entered their local script from `functools`' `from types import GenericAlias` before fixture logic. One complete C# traceback exited 1 with `ImportError: cannot import name 'MappingProxyType' from partially initialized module 'types'` at `libraries/csharp/tests/types.py`; the other four showed the same recursive path. The first five-output diagnostic was piped to `head`, so its shell pipeline status 120 is not asserted as each script's own exit code. This proves a real cold-start shadow, not a full gate result. No backend or provider was reached in the diagnostic.

## What preparation taught us

A filename match became actionable only after checking the actual `python3 "$.../types.py"` calls and observing the cold import recursion. Cwd changes and prior 0249 J1 passes did not establish that boundary. A changed packed request cannot be used to infer a cache hit, and `cache_answers` counts decoded replies rather than records; this preparation makes no cache claim. The 0279 ratchet correction showed why the builder must inspect every configured source counter, including Python fixtures. The five-package build also showed that a static-looking TypeScript shapes check can start a backend and load a native addon, Rust example tests need separately built executables, and the Objective-C soname belongs to `check.sh`'s real producer. The proposed rename batches neither change those routes nor borrow their receipts as new gate passes.
