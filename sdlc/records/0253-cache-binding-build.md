## What the build taught us

The accepted design's selected `Url` type is re-exported from core only for tests; a normal library build initially failed. Passing the already resolved `Backend` through the private inspector repaired that without changing core or public API. Adding the status field pushed `gather` over Clippy's 90-line limit, so cache reporting moved into a local helper. Two test helpers needed `Result` returns to keep strict test lint rather than suppressions. The existing parent cache-identity test pinned the old default sentence outside the original claimed child file; preparation should inventory all exact consumers of a changed diagnostic before the claim. Main extended the claim narrowly and the assertion now passes. The shared safe-open correction is useful beyond status, but does not change the marker write/admission protocol or claim a bounded read on arbitrary hostile filesystems.
