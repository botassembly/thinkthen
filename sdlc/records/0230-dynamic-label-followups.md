The 0230 review lesson has two distinct applications. Dynamic native labels require tracing the **actual** bulk type boundary; they affect Python's proposed list methods but not these decide-only SQL batches. A contextual one-text judgment may enter a record planner even when its host result remains scalar; test the **serialized** detail object, not just the host wrapper or request count. `specification/result.md` requires a record detail's whole `input`, conditional `meta.batch`, batch/profile warnings and exact context digest. 0212's `public/batch/planned.rs::Packet.detail` exists only when an observer is installed, so a result carrier must construct this data independently of a user observer. The proposed 0230 `Details::of_member` can be a shared conversion after its separate review; ADR 0094 at `fb58010a` is a proposed SQL recoverable method, not an approved substitute for Python or C stopping streams. No other port or register outcome is revised by this follow-up.
