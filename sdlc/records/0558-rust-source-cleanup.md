## What the build taught us

Diagnostic context must remain lazy. An initial helper eagerly evaluated a listener snapshot even when an assertion passed, draining observations that later assertions needed. The corrected helper accepts a closure and evaluates it only on failure. The eager helper failed the original listener assertions; the lazy correction passed.

Deleting a wrapper does not prove that its ownership test can use a different result envelope. Existing public compatibility projections cover ordinary details tests; opaque serialization and scalar envelopes require the approved private-primitive transfer when a production caller exists. Expected values, error kinds, positions, facts and send counts remain intact.

Request tests must construct the valid shape for the function they exercise. A scalar image input to rank failed its complete-set admission before image admission. Constructing the valid per-function question and input descriptor preserved the original unsupported-image diagnostics and the zero-send assertion without a routing change or a private guard substitute.

Raw interactive launchers need a separate helper from ordinary command fixtures. The ordinary helper supplies retry and input-pause overrides. Closed-pipe and scheduling cases intentionally omit those overrides, while interrupt cases supply their own retry wait and acknowledgment path. Sharing only environment clearing, caller-owned home and the three pipes preserves these differences. Profile helpers likewise take the verb, question, parallelism and evidence explicitly.

Moving tests increased fixture setup in several slices. Combined counts exposed that growth even when product wrappers disappeared. Shared setup removed repeated construction while preserving the stronger checks; visibility changes alone did not establish a source reduction.

All-target lint reaches fixture code that production-only Clippy omits. A test module duplicated the existing deadline child module, and two image fixture expectation attributes were unfulfilled when compiled inside library tests. Reusing the existing child module and marking the image-only helpers as test code corrected those lint failures without changing assertions or adding lint suppression. Both supported core configurations then passed strict all-target Clippy.

A cancelled collecting Request reports its admission error before creating a batch. The retired wrapper instead returned that same failure through its batch envelope. Tests of the public Request now extract its actual admission error directly and keep the same kind, zero-pull and zero-send assertions. No replacement batch envelope or routing change is introduced.
