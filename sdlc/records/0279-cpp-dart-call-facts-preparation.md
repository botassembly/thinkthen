## What the preparation taught us

The smallest coherent build includes direct callers outside the core doors, especially Dart's public `structured` helper and Flutter facade. Keeping C++ types in `door.hpp` avoids a new release source member. Owned success strings and borrowed failure facts have different lifetimes; both must be copied and freed at their actual boundary. Selected source checks must use a C library whose current header and exported symbols match, since the old release binaries predate 0255.

Fresh High design review caught the initial omission case’s assumption that model disappears with usage. The SystemOne response parser requires model independently of optional usage, and the C facts fixture preserves it. The corrected proof keeps model on that reply and uses the empty call for model absence. No public return or ownership decision changed.
