## Small proof and actual build environments

The minimum source regression is one selected child per binding, not four new full suites. Inside it install a prior hook, panic with a string and with a payload whose `Drop` panics, assert fixed kind/text/non-retry, no marker in return/stdout/stderr, later success, and unrelated-thread host marker. Python needs one additional host-callback suspension row under the same child. R's existing `each_worker_edge_answers_without_a_stray_panic` should retain interrupt, closed-channel and later-success checks while replacing its payload-bearing `boom` expectation. Do not use Python `resume_unwind` as the hook proof. The installed no-fault host case verifies the package being loaded and a later call; it does not manufacture an unreachable packaged panic or replace source secrecy proof.

Use each existing pinned wrapper, not a system tool guess: Python `check.sh` chooses Python 3.12+, `uv` and `maturin`, and `build-wheel.sh` packs offline; Ruby `check.sh` verifies the stamped Ruby 3.4.11 prefix, exports `RUBY`, `PATH`, `LIBCLANG_PATH` found under `/usr/lib/llvm-*/lib`, and invokes `build.sh`; TypeScript `check.sh` chooses pinned Node 22.22.3 and `build-addon.sh`; R `check.sh` uses R 4.2+, `R_LIBS`, `R CMD INSTALL`, then its tarball/outside-repository route. Read these wrappers before any selected command. Keep source child, actual wheel/gem/npm/tarball linkage and host load results separate. MacOS and any other shipped target remain unproved until its own package and interpreter are available; do not infer DSO lifetime or add a self-pin from another port.
