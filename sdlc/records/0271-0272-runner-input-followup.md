## Process lesson

Resolve unavailable dependency names through signed `Provides` metadata before calling an archive uninstallable. Keep package resolution, compiler compatibility, and runner execution as three separate claims. For release archives, compare an exact official asset name, URL and publisher digest with the saved local receipt; an official release page with a collapsed asset widget does not supply that proof.
