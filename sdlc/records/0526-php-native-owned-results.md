## What the build taught us

Recognition publishes incremental aggregates and a final remainder that can be empty. Replacing earlier rows on every aggregate lost valid answers; the current operation retains every chunk. The installed nonempty recognition case exposed the defect. The same overwrite pattern is recorded in the existing Python, Ruby and TypeScript migration tickets for their owners to fix. Relate's single object aggregate retains its intended shape. Existing poll-only generator cleanup remains protected.

A local package fixture used bare tar member names, while the real producer used `./composer.json`. The installer now accepts either layout. Testing the producer exposed another real failure: Composer cannot extract its root `.` member. The PHP-only producer omits that directory entry while retaining every payload file; other package branches and the common packer stay unchanged.

A warm backend executable hid a missing prerequisite. The gate now builds it offline under the existing lock into the path the shared fixture uses. Checking with the executable absent proved the prerequisite, without rebuilding the native product or adding proof machinery.
