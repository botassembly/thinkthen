All source behavior, output fields, defaults, and existing examples remain unchanged.

## What the build taught us

The register captured the right behavior gap but carried two old internal names. Checking today's serialized fields first prevented a new `nearest` promise, and following recognition's current option reader avoided documenting a removed vote function. The review showed that a tie sentence must name what is tied: option probabilities in most verbs, accumulated valid-path scores in recognition step 1, or printed strength when duplicate names compete. It also showed that a default rule example cannot be stated for every verb when `choose` has no default cut. The settings table feeds the site through a parser that expects `none` as the default marker. A truthful contract-page edit must preserve that machine-readable spelling while the site owner updates prose that does not come from the table.
