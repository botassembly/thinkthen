## What the build taught us

Accepted preparation found the split-parent event gap, but a narrow `Stop::begin` inventory was still important after 0300's review had found omitted price routes. The post-reservation send mark is the only sound attempt point; `PreparedAttempt::mark` consumes and releases the usage lock before event delivery. A cached decoded answer and a live attempt are different observations even when the request SHA is identical. `get_all` cardinality must be checked independently for the two headers, and a syntactically valid ID can still echo a secret or request data. The first helper extraction crossed both the `ureq` and vendor-word policy seams; the corrected helper parses plain values only, with HTTP lookup and vendor header selection at their established boundaries. Source-level direct C tests required a real two-entity relation to exercise its transport route. The published API needs an independent fifteen-declaration inventory delta; no public callback is accepted merely because Clippy compiles it. The first lazy-drop proof showed that bounded delivery needs a caller-thread drain in the scheduler join path, including a final drain after workers finish; otherwise completed events disappear and a full channel can block worker exit. Because that drain may invoke a callback during `Drop`, its panic must be held until join completes and then resumed outside any outstanding usage lock.

The tag plan fixture still assumed the pre-0283 single-document output. A passing direct plan command did not qualify that fixture's parser; an independent pre-0302 reproduction separated the stale assertion from timing work. Requiring exactly two complete JSON lines prevents a loose first-line parse from hiding extra output, while the existing listener keeps the actual split and send boundary observable.

The exact all-target Clippy command is a necessary review-entry check. It exposed two large batching functions and then a nested expected-value expression in the same 0302 split fixture. Grouping row metadata kept the row writer at six arguments; extracting only the existing refused-row conversion kept the split function under 90 lines. The literal ordinal table is an independent five-row oracle and preserves the parent's local attribution. Focused source-matched tag/score 11/11 and split-batch 7/7 passed after these changes.
