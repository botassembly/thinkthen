## What the build taught us

The first generated ARM64 manifest used `shasum`'s two-space separator; CMake's existing manifest parser requires one space. That format error stopped configure before linking; the corrected 22-line manifest then passed every archive hash and the exact C++ build. The conformance backend's first offline build lacked `csv-core` because only the bridge manifest had been fetched; fetching the backend manifest into the isolated Cargo cache resolved it without a source change. The existing manylinux ARM64 image, official Rust toolchain and checked ZIPs produce a stock-loadable C++ extension with the reviewed find route. The release-container's former x86-only DuckDB input branch and the package notice helper's former fixed x86 inventory were both necessary target-map fixes. The historical settings corpus file-count assumption became visible only when the native installed checks exercised recording on current main; its actual listener and saved-body expectations still pass after the narrow correction.
