## Small proof and stop conditions

First implementable slice after source refresh: one Rust `decide_many`/`filter` loopback table compares default full-batch and `batch 1` exact bodies/digests and listener count against the existing fixtures, then one filtered result plus retry checks per-call totals and ordered observations for both retained and suppressed rows. A separate compact choose/score/tag table proves typed null, label order and first failed record. One eager failure checks `Error::facts()`; one lazy terminal error after a later in-flight reply checks identical final `Batch::facts()`, counted attempts/replies and no later row observation. One shared spelling fixture checks another-language digest against the Rust bytes without a second serializer in product code. Reuse the existing public cancellation/stop boundary and add only a regression that batching changes. Format, focused strict lint including relevant features, policy/file-size and selected public/conformance checks precede any broad rung. No live, load, stress or provider call is part of this design.

The 0172 source is landed, so its former hold is no longer a prerequisite. Nonoverlapping Rust preparation can proceed while 0149/0157 remain active, but their held files need an exact release or landing before edits. Stop before runtime public-shape work if independent design review rejects the recommended uniform `Call<T>`, bounded question/row observation and error/final-facts contract; return a concrete alternative for review rather than asking the code reviewer to invent it. A failed proof that `ask_batch` can feed lazy rows while preserving the current stop order also returns to design review. Do not call old branch tests integrated, infer exact call facts by process-counter deltas, or close global register 19/78 before their later wrappers are checked. 0213's proposed ADR 0090 raises a separate future planner extension: fixed typed `choose_many` does not need per-row option identity, but any dynamic-option reuse must compare selected evidence plus complete question and keep the existing record-byte content cut.
