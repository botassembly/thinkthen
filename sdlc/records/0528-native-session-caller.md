## What the build taught us

Counted native text must preserve embedded NUL bytes. The earlier installed regression caught terminated-string conversion, which was replaced with an exact counted-byte copy. Packet JSON is borrowed from the packet owner: freeing that pointer separately double-frees storage, so only the packet release owns cleanup. Cancellation fixtures must forward their subprocess streams so the existing process-lifetime checks can observe cleanup.

Retiring a host API must preserve useful auxiliary capabilities and name any remaining limitation. Ada keeps native preview ownership explicitly instead of claiming a typed Plan carrier that the shared header does not provide.
