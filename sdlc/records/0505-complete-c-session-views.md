## What the build taught us

Generated views need one lifetime owner: conversion borrows packet slices instead of independently copying and freeing nested JSON subtrees. Native status exports report their diagnostic on the calling thread; the earlier Swift adopter was corrected to read that diagnostic rather than an unrelated saved engine error. Zig surface attribution uses the generated surface constructor so facts name the actual caller.

Tests must install the actual package, retain results after owner teardown and compare typed values, not stop at source compilation. Package-isolation fixtures must move with the current consumer rather than keep references to deleted Go or Swift test entry points.
