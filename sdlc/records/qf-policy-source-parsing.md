It found `check_doors` at 13.5187 seconds and `check_facade` at 28.7550 seconds in a 45.8558-second zero-failure run. The experiment artifacts remain local and unpushed.

Both checks already read a fresh source map when called. Their plant and control loops then lexed every unchanged file again for each single-file mutation. The facade's required `Client::new` scan also lexed its file at every token position. Each check now builds its own local token map from its fresh source read. A plant or control lexes only its complete modified file and overlays those tokens on the unchanged map. The facade keeps raw tokens for its existing required-presence check and filtered tokens for its bypass rule, preserving the distinction when `Client::new` appears in a test module. No source persists across checks or calls. The lexer, rule tables, plants, controls, thresholds, and diagnostics stay unchanged.
