## What the proof taught us

The installed native-library path resolves `/tmp` to `/private/tmp` on macOS. The first smoke probe rejected its own literal path comparison after the product assertions had passed; comparing canonical paths corrected the probe without changing the package. Package load and zero-send lifecycle can be proved with a small installed call, but those observations cannot stand in for a caught-panic witness.

The R package's offline build stopped on an absent locked `extendr-api` cache entry. A dedicated locked fetch restored the intended offline install. Zerobrew R then exposed a stale absolute `libR.dylib` install name to the documentation helper; a temporary cargo-launch environment supplied the real library directory without changing the R keg or repository. The resulting library targets macOS 26.0, so this is local host evidence rather than the advertised macOS 15 package proof.
