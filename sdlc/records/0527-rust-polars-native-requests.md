# Rust and Rust Polars installed closure

Rust callers use explicit owned Engine methods and typed native inputs/results. Rust Polars exposes all ten functions through native columns, typed complete results and borrowed row methods. Native Request admission owns question grammar, reading, options, limits, cache and execution. Current methods used by Request execution, the CLI and frozen C remain.

The closure deletes unused global judging/image aliases, the copied Python native-case dispatcher, copied Polars settings and the fixture dependency on the legacy host dispatcher. Installed Rust and Polars consumers now link directly to the unpacked Rust crate and exercise its public typed APIs. READMEs name the replacement calls. Hidden `default_engine` and `usage` remain solely for the four live R/Python/Ruby/TypeScript adapters recorded in 0511; their last owning family removes those names. This is support for pending retirements, not a second recommended judging API.

## What the build taught us

The earlier Polars migration moved named, complete and borrowed APIs onto Request execution while preserving original ownership, null positions and whole-set semantics. Closure keeps those useful APIs and deletes unreachable aliases rather than wrapping them in another generic JSON endpoint. The installed consumers must call native typed APIs directly; a copied host dispatcher did not establish that boundary.

A malformed fixture descriptor must retain a typed usage refusal rather than exit while parsing fixture input. Structural annotation documents must preserve parsed JSON through the native document reader. Null context data belongs in the original record and is selected through native field/context-field reading; a null RequestItem context is a different, invalid descriptor. Correcting these mappings preserves the exact shared schema refusal and zero sends without changing native grammar or expected answers.

Nonempty recognition cases protect aggregate retention. Polars retains every row and completed prefix; the direct Rust consumer owns the complete RequestOutcome. The initial Polars test invocation omitted its isolated fake-key setting and refused before work; the corrected invocation uses the existing environment helper and passes. No service credential or private input was used.
