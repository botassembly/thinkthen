## What the build taught us

The original virtual-table callback copied hidden arguments before the host could compare them. The borrowed `xFilter` path was necessary; optional outer-row key constraints also had to remain with SQLite when unavailable to a particular plan, or correlated queries failed with `no query solution`. The first correlated proof expected one send from a thousand rows, but the actual packed default split made three; its corrected assertion pins three independent listener arrivals and no new sends on the second probe. The first example failure was a malformed JSON brace in the SQL literal, which a bound fixture did not exercise. The shared parser accepts C's `base_url`, while SQL must keep address control in the environment. A named question file with nondefault settings needs the existing local error kind after merge, now pinned with zero sends. Clippy exposed nesting in the first keyed scan; extracting conversions preserved the selected wire and row proofs.
