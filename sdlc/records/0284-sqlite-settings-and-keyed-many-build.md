## What the build taught us

The original virtual-table callback copied hidden arguments before comparison, so the borrowed `xFilter` path was necessary. The first preparation missed that a planner's candidate key lookup does not implement SQLite's comparison rules: a pushed constraint still needs SQLite's residual check, and NULL or nonbinary equality may require all candidates. It also missed that JSON maps silently flatten duplicate keys and that memoized rows need the question file's freshness stamp. These lessons apply to future host memoization. The original correlated query failed with `no query solution` when an unavailable outer-row key constraint was treated as required; its fixed test pins three real packed arrivals for 1,000 records and no new arrival in the second probe. The first example failure came from a missing JSON brace in a SQL literal. SQLite keeps the shared parser but refuses C's `base_url`; a named question file with nondefault settings retains its `local` error kind. Clippy drove extraction of answer, batch and removed-name conversion, and the final source/installed proof kept the 0289 API and SQLite archive identities separate.
