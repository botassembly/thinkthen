## What the build taught us

The source report's frame-schema failure mixed a genuine new `failed` column with an unproven inference that every answer failed. The generic backend and weighted-score code supplied independent expected values; the corrected test pins both values and the null failure marker. The original cap and held tests counted groups as requests although the default planner packs short rows. A three-row exact body pair and eight independent held groups test the intended properties without changing packing or weakening counts. The Python beta was the Pydantic mismatch; a reused venv must prove its own interpreter identity before its green cases count. The core settings parser admits explicit null description fields, so a wrapper may not discard them or call them invalid just to simplify a refusal table. The existing owned observations already carry probability, and the existing process reservation already owns the cap; no second send or local counter was needed.

A nullable representation also retains structural validation over slots whose payload is ignored. The first correction correctly skipped null payload bytes but accidentally skipped their offset metadata. The next joint 0292/0293/0294 Judge, Stream and Tally entrypoints must keep that distinction while carrying the same public null-in/null-out contract.

The preparation and prior selected check inherited the old column-null refusal as an expectation and covered null *answers* without a null *input*. That missed T5's already settled input rule. The joint 0292/0293/0294 Judge/Stream/Tally boundary must keep null input places distinct from unresolved answers and failures; 0295's Polars expression morsels and 0296's pandas accessor must carry the same null-in/null-out property through their own supported entrypoints, with body/count and index checks. This is a proof handoff, not an added API feature for 0287.

The full `check.sh` package campaign, pandas 2 lane, stress/RSS campaign, release wheel, other platforms, provider acceptance and later Judge/Stream/Tally work remain unrun. This candidate does not close the broader clean-package issue or claim those qualifications.
