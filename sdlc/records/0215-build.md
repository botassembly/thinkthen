## What the build taught us

The preparation's parser/schema/corpus inventory and wire-versus-logical warning were correct and prevented a silent second-row tag failure. It missed that the original args parent had only five nonblank lines of headroom after B8, so a coherent extraction was needed even though the runtime change is small. The one-document and result metadata paths stayed shared, avoiding another completion adapter. The first boundary test mistakenly counted a drained listener twice and assumed concurrent request arrival order; both were test-harness assumptions, not runtime faults. A complete metadata inventory showed that result.schema.json permits additional `meta` keys without typing them, so the public table and compiled rows are the honest contract proof. The paid preflight proved that 219 title records group as 219/3 tag and 219/1 score requests; no default count was guessed from the old 158/171 suites. The benchmark's page-view score is a proxy and must remain labeled as one in the later result.
