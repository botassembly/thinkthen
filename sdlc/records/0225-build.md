## What the build taught us

The first compile showed that `File::try_lock` returns `TryLockError`, not `io::Error`; matching `WouldBlock` fixed the helper without changing the policy. The first compiled edge run showed `Listener::serving` tracks observed requests through `requests()`; `count()` belongs to the other listener route. The corrected test passes and keeps independent expected output, counts and files. The original preparation correctly named `Drop` and multi-month `taken` writes as the places a finish-only or per-month timeout would miss. It did not anticipate the standard-library error type or listener counter distinction. Fresh review should check the shared deadline and cleanup, then the coordinator can close register 31 if the reviewed candidate lands.
