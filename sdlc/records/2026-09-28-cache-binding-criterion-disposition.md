# Register 10 cache-binding criterion disposition

Status: recommendation for fresh review, not a row/status/count edit. Source read at `3918bba2`. Original: `$HOME/workspace/experiments/284-issue-register/10-d5-default-cache-binds-address.md`. Its literal success test asks that **every zero-send run leave the default folder untouched** and that a mismatch name **both** bound and requested addresses with a cure on command and library surfaces.

## Reconciliation

Accepted ticket 0065 and ADR 0035 require one synced private backend marker **before a permitted send**, so different-address first writers cannot both send. `core/recording_identity.rs` stores only a closed adapter-and-canonical-address SHA-256, not a recoverable URL. `engine/recorder/identity.rs::check/publish` verifies or atomically publishes under the folder gate; `engine/request.rs::ask_prepared` prepares the write-capable recorder before the final HTTP attempt. A cancellation, deadline, crash or transport ambiguity after admission can leave a valid marker even if a listener saw no request. Moving publication to entry installation, deleting a marker after an unsent result, or storing a raw bound URL would change the accepted cross-address safety, shared lock/inode lifecycle, privacy, and old-reader marker contract. This is a contract conflict, not an unimplemented cleanup step.

Three exact pre-admission cases **are fixed**: 0228/ADR 0099's absent-key first-use probe, 0246's explicit zero send limit, and 0250's CR/LF key refusal. Those reviewed outside-in cases pin unchanged absent or present-empty folder, zero loopback sends and later second-address use while retaining gate-first mismatch/legacy/malformed refusal and racing-writer handling. Pre-fired cancel and already-expired deadline also stop before writable admission. These do **not** establish the universal zero-send sentence; the 0250 private post-admission stop is a source/proof counterexample with a valid marker and no entry.

Ticket 0124's CLI mismatch prints the **requested** address and an actionable default/named-folder cure. 0250 adds a fixed cure to the library's nonretryable Local mismatch message. Neither prints the **bound** address because the marker cannot recover it; `cli/failure/recording.rs`, `public/error.rs`, and `specification/recording.md` reflect that limit. A safe public comparison against a requested address could report equality, but still would not satisfy the original two-address demand. A status line or explicit unbind workflow was deferred by 0124 and is not required to preserve the accepted safety rule.

**Recommended coordinator ruling:** retain the before-send hash marker and safe cures; explicitly reject the original universal no-touch and recoverable bound-address wording as incompatible with accepted 0065/ADR 0035 and the closed marker. Under the stated table rule (`done` = code fixed; `nonissue` = already fixed or disagreed approach), classify register 10 as **nonissue / disagreed approach after review**, not `done` and not silently “fixed by 0250.” Keep the narrower pre-admission fixes credited to their actual tickets. No fresh pre-admission refusal is demonstrated on this revision; a newly observed deterministic case should get its own bounded proof and claim. No marker rollback, raw-URL sidecar, schema migration, unsafe deletion, provider call or new runtime work follows from this disposition.
