## Question-file version (85)

Register 85 is distinct from recording vintage. Its success criterion is an optional user version in a **single-question** file, visible in result `meta` and included in question identity. `specification/question-file.md` currently explicitly refuses `version` for decide/choose/tag/score and directs it to a question set, recognize file or relate file; `core/question_file.rs::EVERY_KEY` and its version diagnostic implement that rule. `core/digest.rs::Canonical` uses the effective question/rule/profile and no single-file version; `specification/result.md` lists no version in scalar `meta`. A file rename or existing `question_sha256` is not the requested human version. This is a new grammar/result/digest choice, not a replay or cache repair. Before a build, review the interaction with ADR 0013's file/CLI equivalence and digest rule, accepted structured question forms, schema/corpus, public details and SQL hosts; then claim exact files. One named file, an equivalent direct question, a changed version with unchanged question text, and one invalid version would be the minimal outside-in table. Keep this behind the correctness and page remainders; do not edit grammar from these notes.
