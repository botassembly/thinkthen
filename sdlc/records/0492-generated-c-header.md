## Dependency decision

The reviewed external tool is cbindgen 0.29.4. The standard library provides file and process operations; it provides no Rust syntax tree, module traversal, Rust declaration parser or C declarator generator. cbindgen supplies those facilities. Its [versioned documentation](https://github.com/mozilla/cbindgen/blob/v0.29.4/docs.md) describes stable source parsing, dependency parsing and export renaming; its [Cargo manifest](https://github.com/mozilla/cbindgen/blob/v0.29.4/Cargo.toml) declares MPL-2.0. The tool remains outside every product runtime, build and development Cargo dependency graph. No product manifest or lockfile adds it, and no product license allowance changes. Gate setup installs the standalone CLI. The generation script checks its exact version before parsing the crate root and its modules directly without Cargo metadata. It writes no product lockfile. It uses no nightly expansion, compiler bootstrap variable, expansion flag or generated-header filter.

## Interface and memory decisions

Public carrier and export declarations replace macros that hid them from stable parsing. Shared execution, admission and publication helpers retain behavior. The C spelling map holds names without restating layouts or values. The native cancellation token has one opaque forward declaration because dependency parsing remains disabled. That declaration supplies no implementation, fields, size or ownership wrapper. Other handles remain opaque because their Rust storage lacks a C representation.

The generated unions have names, while their parents preserve `data.decide` and the other arm paths. The existing Clang declaration reader now resolves those named unions and retains nested field offsets in its target-compiler probes. The source compiler comparison preserves every prior public carrier size, alignment, field offset, prototype and constant value; the generated header adds only the union typedef names. Descriptor discriminators retain uint32 storage and validation, so an unknown caller value never constructs a Rust enum. Native mappings consume the same Rust values that generate the C declarations. Author grammar descriptors derive their internal uint32 values from their canonical Rust enumerators.

Union defaults initialize bounded zero-valid storage at `libraries/c/src/ffi/carriers/zero/ffi.rs`. Every arm in these unions contains only integers, floats, nullable raw pointers and C carriers recursively composed of those types. No arm contains references, `NonNull`, nonzero integers or Rust enums. Parent discriminators select meaningful arms after construction. Tests read zero-valid typed fields and absence flags, not padding bytes: Rust does not promise to preserve padding through moves. The previous full-byte union tests depended on private byte-array arms that the source parser could not represent. Their logical zero and absence contracts remain tested. The independent reviewer must inspect this unsafe initialization and every union arm.

The existing `call/legacy.rs` translator exceeded the function line limit before this change. A small refusal helper preserves its filter-band validation order and error text. The complete rank projection also shares its repeated observation lookup to keep the function within the existing limit. The expanded FFI source files warn at the source ceiling's advisory boundary because they now expose the public declarations and carry their C ownership comments. Those declarations belong at the C boundary; the helpers retain the shared implementation. The generated header alone joins the policy's exact generated-file exclusions, and the generation drift gate continues to check it.

## What the build taught us

Source generation can remove declaration drift while preserving independent compiler and consumer checks. Stable parsing needs visible declarations, but behavior can remain in shared helpers. Private initialization storage must not become an additional C layout contract. Typed validity and active-arm rules give the useful memory contract; padding-byte scans do not.

Generated spelling changes must reach shared ABI readers as compiler-proven equivalences. Full host smoke checks exposed assumptions that source-only compiler checks could not. Version updates must stage the Rust proposal and generate the header before writing any files. Keep the checkout commit fixed while workflow fixtures resolve and compare it.
