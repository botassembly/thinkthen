## Growth, consolidation and lessons

Measured host ratchets move Go `.go` 1034 to 1189 (+155), PHP `.php` 366 to 433 (+67), Go fixture `.py` 565 to 581 (+16), and PHP fixture `.py` 750 to 769 (+19). The added lines cover one Go typed facts decoder/result carrier, native output ownership in four routes, migrated existing assertions, the PHP validation/ownership paths and one narrow missing-usage reply condition per host. I checked the four wrapper routes and existing copied-source tests for duplicate decoding, independent call loops and bare-result aliases; Go decoding is shared in `result.go`, PHP validation is shared in `facts()`, and existing failure/cancellation tests were retained. No new provider fixture or body corpus was added.

The stale native release library showed why export presence and matching source matter before host proof. Go silently accepts missing or null numeric keys as zero unless presence is checked before struct decoding. PHP's `relate` case returns `facts.records=1` for two entities because that call judges one logical relation question. The narrow omitted-usage source cases needed separate counted runs, registered in each host matrix, so the older exact request inventories did not change. The full four-consumer Go matrix was not rerun for this bounded change; its new copied-module `-race` selector was exercised separately. No test was deleted; the existing parser, failure, cancellation, ownership, order and package cases remain.
