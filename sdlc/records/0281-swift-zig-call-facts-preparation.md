# 0281 Swift/Zig typed call facts preparation

Date: 2026-09-29. Source pin: `origin/main` `c4202fbc0`. This was read-only design preparation; no build, provider, package, runner or host fixture ran. The [ticket](../tickets/0281-swift-zig-call-facts.md) is the bounded implementation handoff.

## Actual current routes and contract

`libraries/swift/Sources/ThinkThen/ThinkThen.swift` returns bare `Answer`, `[Answer]`, `String`, `String` from `decide`, `decideMany`, `recognize`, `relate`. The first pair calls old C `_opts`; the second pair calls old C plain forms and exposes no options. Swift `call` already returns the C JSON `value`/`facts` envelope; `DoorFailure.factsJSON` copies started-failure facts immediately. `Engine` is `@unchecked Sendable` but requires callers to join calls before close; tokens must outlive calls. `libraries/zig/src/thinkthen.zig` returns bare success payloads in `Result(T)` from the same four old `_opts` forms. Its `call` already carries JSON facts and `capture` copies borrowed failure facts; the caller owns successful byte/answer slices and failure strings with the engine allocator and joins concurrent calls before `deinit`. Both wrappers retain six C error kinds. These actual routes require four migrated methods per host; seven other JSON-only verbs and process usage need no typed route.

The current `libraries/c/include/thinkthen.h` declares all four `_with_facts_opts` symbols with independent owned facts pointer/length beside the result; on nonzero return it changes no output slot and exposes started-failure facts through the borrowed same-thread error slot. Swift's vendored C header matches it byte-for-byte at this pin; Zig imports the C header. `libraries/c/tests/c/typed_facts.c` and accepted 0255 pin C ownership, zero bulk and optional usage. ADR 0101 preserves only old **C** bare exports. ADR 0106 settles the wrapper result choice. Native `facts.records` counts finished ordered rows and excludes a failed row (ADR 0089 item 3); `requests_sent` may include the failed attempt. The accepted 0277 Go/PHP proof found a two-entity relate call can have one logical question, and its initial concurrent witness needed both backend arrivals before release. Swift/Zig tests must not turn entity count or requests sent into a fabricated record count.

Source proof, installed-source copy, clean archive and actual runner qualification remain different claims.

## Design lesson and next step

The important boundary is two independently owned native outputs, not a new facts computation. Swift needs strict numeric decoding that keeps JSON booleans and null distinct from counts, and defers both frees on a throwing conversion. Zig needs an owned success carrier whose allocator and deinit rule cover answer/string slices plus optional model, with partial-allocation cleanup and no borrowed C memory. A concurrency check is meaningful only when **both** native requests have arrived before either is released; later-call and close checks then establish snapshot ownership. The ticket states the exact migration and selected proof. Fresh High review and a root product claim precede code. Other wrappers and SQL/DataFrame work are outside 0281.
