## Distinctive proof and limits

Reuse each host's current exact wire-body/order checks and held backend markers, C 0255 native pointer proof, and 0277–0281 facts lessons. One typed success per real route plus one invalid-facts decoder table establishes host conversion; do not clone a field-by-route matrix. For cache, replay the **identical complete packed request**: three records can be one cached answer and zero sends; record count alone does not imply cache count. A valid no-usage reply still names a model; independently use empty Objective-C bulk for absent model. Ada's empty bulk is locally refused, so retain its no-send refusal instead of changing accepted behavior. Native first-row failure can have records zero and one sent request; two relation entities can form one question. Read typed failure facts before a later operation, then prove retained value through later call and close. An overlap claim requires both held requests to arrive before either release, not merely launched tasks. COBOL has no new overlap claim.

For selected proof, use source compilation and the current matching C facts exports, the existing Ada typed matrix and copied consumer, Objective-C matrix and copied consumer, and an extended COBOL installed check that actually compiles/executes `TT-DECIDE` from copied source. Keep source, copied installed source, clean release archive, and actual runner receipts separate. `libraries/{ada,objective-c,cobol}/check.sh` run complete C/backend/host gates and installed release mode requires two matching archives; do not launch them just for this bounded change. No provider, all-port or SQL/DataFrame work. The every-call umbrella's full detail, cost, server/request timing and ID criteria remain open.

## What preparation taught us

The three hosts do not have identical typed verb sets: COBOL has one facade verb, Ada has four procedures with an existing empty-bulk refusal, and Objective-C has four methods plus counted forwarding variants. COBOL's installed proof currently misses its typed facade despite copying its source, so the future build must add one copied typed consumer. Objective-C owns its structured result with `malloc` while C owns the native result and facts independently; one cleanup path cannot stand in for the other. Ada's controlled strings already distinguish Ada and C allocation. These facts determine a single coherent claim without editing the JSON corpus or source during preparation.
