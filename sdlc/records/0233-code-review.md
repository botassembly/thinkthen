1. A mixed typed score Enum produced a map whose absent member had value `null`. The native score grammar sends an empty object for map null, while a bare level sends its name. The reviewer captured `[{}, "very high"]` where `["low", "very high"]` was intended. The correction uses the bare name only for a typed score member with *absent* metadata when a mixed map is required. The listener regression pins the exact body and digest against the equivalent old map, while a separate explicit-null map and typed `descriptions={"low": None}` still produce `{}` and their own digest. Choose/tag behavior and old maps are unchanged.
2. `_field_kind` stripped `None` from every union. The reviewer showed `float | None` was accepted as a score model field even though `row_model()` rejects null scores. The correction accepts only `bool | None`, `Literal[...] | None`, bare `float`, and bare `list[Literal[...]]`. The successful Pydantic model exercises all four forms; nullable score/tag and bare decide/choose models are refused by both annotation before any send and row-model creation.
