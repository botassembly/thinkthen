## What preparation taught us

The earlier SQL designs could reuse a many-record host adapter, but DuckDB already has several grouping layers: C++ deduplicates vector rows, Rust still asks per text, and warm sorts aggregate evidence. Reading `StatementOwner` separates one statement budget from per-group trailing deadlines. Reading the actual tests exposed held-send counts and old exact exchanges that a default-packed implementation would invalidate. The three other platform packages have their own C API path and cannot inherit Linux C++ results. Compare this inventory with implementation and fresh review; correct any missing constructor or count before widening claims.
