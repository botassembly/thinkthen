## What the build taught us

A repair must handle the empty object left after removing old fields. A safe diagnostic needs catalog names and a fixed field list. Owned offline Cargo configuration must preserve shared cache locks and point at the advisory database root. Separate refusal and repair tests preserve distinct behavior while respecting the existing size and complexity limits. Full-gate contention can expire a short test deadline before its observation handshake; lowering concurrency preserves its assertions. Real configuration migration, unavailable binding smokes and release qualification remain outside this ticket.
