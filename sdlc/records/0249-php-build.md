## What the build taught us

The copied package lacked its experiment gate and fixtures. The current source gate therefore owns its own product paths and compares copied installed bytes. The old README's `target/release` path was wrong for a build using `--manifest-path libraries/c/Cargo.toml`; the source recipe now uses `libraries/c/target/release`. A stopped backend request can have `requests_sent:1` with no returned record, so the failure-facts assertion checks the sent request and does not infer a successful record. The old C export count was stale, while the PHP public contract only requires the C functions its API uses. A broken settings route in the environment plus a working constructor route distinguishes actual constructor precedence from a constructor that is merely callable. The test-only raw native handle exposed an unnecessary public escape hatch; a fixture can inspect the installed C ABI without shipping that method.
