## What the build taught us

Test the artifact a caller receives. Source consumers, archive simulations and loader checks each answer useful narrower questions, but none replaces an installed package using its ordinary dependency route. Package producers and checkers must derive source members, native targets and runtime floors from their existing owners; repeated handwritten inventories caused the assembly drift.

Keep JSON conversion independent of the caller's locale. Advance producers through every public consumption mode. Release a producer once, preserve the active native failure and completed prefix, and keep standalone cleanup failures visible. Cancellation must release native ownership without waiting for arbitrary caller cleanup.

Admit required NULLs before partner validation or observable settings work, including statement callbacks and public file helpers. Admit per-record controls before rebuilding or clearing their carrier. A shared engine cannot protect fields discarded before it receives them.

Reuse applicable proof and state its boundary. The cap prevented compilation and installed confirmation for four source repairs; repeating source checks would not resolve that gap. This record changes no source ceiling and creates no proof tooling or additional language records.
