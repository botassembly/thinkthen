# SQLite native Request bridge

Ticket: [0499](../tickets/0499-adopt-request-sqlite.md). Starting revision: `27017f36d7fa05c26f0b8613af0b3acbfb67c698`. Initial qualification source: `86c2686889e8e501699b227fb36676cf4d75fe38`. Final integrated production source: `efd0129d0011eef1e85993b3355f643d5a935245`. This record covers the ten named `thinkthen_*_complete` functions and the shared composed-record bridge. It does not establish the whole SQLite migration or release qualification. Ticket and lane status remain in pm.

SQLite translates host arguments into native `Request` definitions and executes through `Engine::execute_request`. It never serializes a native Request to call Rust. Its authorized saved-question resolver, SQL spelling, complete carrier, typed result values, source positions, callbacks and settings remain at the host edge. Typed native output supplies complete results and failures; the adapter adds existing SQL ordinal and selected-find conventions.

`RequestFeed::from_records` accepts already composed native rows with their originals, locations, images, context, candidates, examples and recognition seeds. It owns framing and projection, so additional Request framing, projections or shared attachments refuse before iterator advancement. `eager` validates the entire feed before sends; incremental execution retains the actual successful prefix. Declaration, candidate, recognition-control, cancellation, image-function, image-route and existing engine bounds still apply. Caller-known image descriptors permit early refusal through `with_image_inputs`; omitting the marker never waives actual row validation.

`AdmittedRequest::record_reading` reuses shared typed projection for admitted inline definitions. Unresolved saved selectors refuse without I/O. SQLite applies that reading while composing atomic, rank and dynamic-choose rows, retains its native find/recognize file reading, and preserves explicit SQL reading descriptors. Top-level SQL input fields and flags parse before saved-question resolution. Shared definition admission precedes engine creation. PostgreSQL retains its previous dispatcher and descriptor grammar until 0500; the SQLite-only execution module does not change PostgreSQL behavior.

## Retained limits

Legacy scalar/table execution still calls Engine directly: `src/scalars.rs` uses primitive details/decide and annotation; `src/scalars/find.rs` uses find; `src/tables.rs` uses recognize/relate; `src/many.rs` uses details-many/rank; `src/rank_set.rs` uses rank-set; `src/images.rs` uses image details; and `src/recognize_document.rs` uses recognize. Existing keyed lookup, file readers, question helpers and scalar planning remain coupled to those paths. The old `complete_native` dispatcher is retained for PostgreSQL 0500. Whole-surface migration must replace these paths while preserving SQL conventions.

Canonical saved-selector translation remains separate work. This adapter resolves saved questions through SQL's existing safe resolver before constructing an inline-definition Request. Top-level malformed descriptors refuse first; deeper reading/row descriptors are still admitted later by the existing host composer and native feed. The installed definition-path results therefore do not prove all canonical selector admission before saved-question I/O. Generated projections must also absorb subsequent approved shared fields before whole-contract qualification. No canonical schema expansion was made here.

## What the build taught us

A composed-record bridge must validate rows at the same semantic stage as ordinary Request composition. Checking only the function header misses declarations and recognition controls; validating before authored selection rejects valid objects. Reusing native typed reading and shared row admission preserves both contracts without another grammar or weakened tests.

Required-case execution and installed loading are separate evidence. A zero-case selector cannot qualify a consumer, and a warm library cannot qualify changed source. Count the actual sends and cases, retain real failed exits, and distinguish production regressions from stale fixture expectations.
