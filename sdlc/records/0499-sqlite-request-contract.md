Ticket: [0499](../tickets/0499-adopt-request-sqlite.md). Starting revision: `27017f36d7fa05c26f0b8613af0b3acbfb67c698`. Initial qualification source: `86c2686889e8e501699b227fb36676cf4d75fe38`. This record covers the ten named `thinkthen_*_complete` functions and the shared composed-record bridge. It does not establish the whole SQLite migration or release qualification. Ticket and lane status remain in pm.

SQLite translates host arguments into native `Request` definitions and executes through `Engine::execute_request`. It never serializes a native Request to call Rust. Its authorized saved-question resolver, SQL spelling, complete carrier, typed result values, source positions, callbacks and settings remain at the host edge. Typed native output supplies complete results and failures; the adapter adds existing SQL ordinal and selected-find conventions.

`RequestFeed::from_records` accepts already composed native rows with their originals, locations, images, context, candidates, examples and recognition seeds. It owns framing and projection, so additional Request framing, projections or shared attachments refuse before iterator advancement. `eager` validates the entire feed before sends; incremental execution retains the actual successful prefix. Declaration, candidate, recognition-control, cancellation, image-function, image-route and existing engine bounds still apply. Caller-known image descriptors permit early refusal through `with_image_inputs`; omitting the marker never waives actual row validation.

`AdmittedRequest::record_reading` reuses shared typed projection for admitted inline definitions. Unresolved saved selectors refuse without I/O. SQLite applies that reading while composing atomic, rank and dynamic-choose rows, retains its native find/recognize file reading, and preserves explicit SQL reading descriptors. Top-level SQL input fields and flags parse before saved-question resolution. Shared definition admission precedes engine creation. PostgreSQL retains its previous dispatcher and descriptor grammar until 0500; the SQLite-only execution module does not change PostgreSQL behavior.
