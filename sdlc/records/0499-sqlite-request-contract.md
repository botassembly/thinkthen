## What the build taught us

Eager Request admission knows the entire record set and may refuse before any request. A streaming consumer can have a different partial-submission result. Assert each documented contract directly rather than reuse the old dispatcher expectation.

Audit the actual routine runner for large fixtures. A routine profile label does not exclude a large case that a test module invokes unconditionally. Preserve those boundary assertions in the release profile and keep installed routine checks small.

Count justified deletion once. Moving shared preparation into its own crate and deleting its dispatcher does not require another refactor at SQLite closure.
