## Limits and what the build taught us

The focused check did not run JVM, C#, Dart/Flutter, Swift, Zig, R or every installed package on actual host SDKs. It did not run full lint or any provider call. The first local loopback attempt was denied by the sandbox; the authorized narrow loopback run completed with the plant. The first plant wrapper also tried to read its marker-log path from an environment variable; isolation correctly removed it, so the test-owned wrapper was changed to use its literal temporary path. Neither transient failure changed repository code or weakened the oracle.

The scanner caught an overlooked COBOL compiler line; scan every child boundary after a mechanical conversion. A child helper with an optional selector must preserve absence as absence. Clean ABI grandchildren require clean parent-to-Python handoffs. No test was deleted or consolidated; no permanent test-only hook or framework was introduced. The held DuckDB finding and actual host qualification remain separate from the 45-library-code result.
