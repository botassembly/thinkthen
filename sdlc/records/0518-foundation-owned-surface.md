## What the build taught us

Deleting a platform-specific API must also remove its impossible package routes and fixture assumptions. A Linux GNU runner cannot establish Foundation behavior. Platform qualification can move to the candidate while the replacement execution route is built now.

Early task cancellation and a fully drained native session have different fact availability. Exercise each public contract directly rather than fabricate final counts or weaken shared expected results. Missing-package checks should observe actual refusal, not inspect a consumer's shell spelling.
