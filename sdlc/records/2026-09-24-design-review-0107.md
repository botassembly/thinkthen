## Findings

1. **R3-25 cannot pass as written, and its plant cannot turn red.** `default_engine()` omits width. Ticket 0077 gives an omitted width the fallback of 4, and `from_env` reads no width variable. So `W` is 4. In the pool-of-8 child, five held calls stop at 4 counted, never 5. In the pool-of-4 child, the spawned-thread plant also stops at 4, because the width gate holds it there. Fix: state `W = 4` and its source (0077). Run the child with `UV_THREADPOOL_SIZE=2`. The count reaches 2 and stays at 2 for 300 ms. Under the plant it reaches 4. Replace the pool-of-8 half with a pool of 4 that reaches 4.

2. **The deny plant fails before deny's `sources` rule runs.** I ran it: a git dependency under `--offline` stops in `cargo metadata` with "can't checkout … you are in the offline mode". So the step turns red for the wrong reason. Two plants do reach their rule, and I checked both. (a) A local path crate with `license = "GPL-3.0-only"`, which the `licenses` check rejects offline. (b) A `file://` git repository fetched once without `--offline`, with no network. The `sources` check then reports `source-not-allowed`. Fix: use one of them, and pin the diagnostic the record must show. 0105 has the same gap, and its builder should take the same fix.

3. **Two binaries the tests need have no stated source.** The R2-27 shapes test compares `tt.details` with the command's `--details` output. `check.sh` passes no path to the `thinkthen` command. The backend path depends on the root `test` rung having run first. Running `sdlc/scripts/surfaces` alone could find no backend binary, or a stale one. Fix: `check.sh` builds both with `cargo build --locked --offline` (`-p conformance-backend`, and `thinkthen` with its default `cli` feature) and exports both paths. Or compare `details` with the case file's expected document and drop the command dependency.

4. **The pack assertion is false.** "The pack list holds exactly the `files` entries" cannot hold. npm always adds `package.json` and `README.md`. I observed it with `npm pack --dry-run --json --offline`. Fix: the expected list is the six `files` entries plus `package.json` and `README.md`.

5. **The npm half of R4-14 has no owner.** R4-14 is filed under `python` and includes "npm pack ships no LICENSE". 0105 carried only the Python half. Here, the R1-34 plant removes the `license` field and leaves the `LICENSE` file untested. Fix: add an "R4-14 TypeScript half" row. The re-proof is `LICENSE` in the pack list. The plant drops `LICENSE` from `files`, and the pack check fails.

6. **A dropped task keeps the process alive.** The abort race settles the promise at once. The native work is still a libuv work request, so Node's event loop cannot exit until that send ends, for up to the 30-second request timeout. Python's detached worker does not hold its interpreter open this way. Fix: name this cost in decision 5 and in the "Differences from Python" section. Add an assertion to the single-abort test: the child's script ends right after the abort, and the child exits only after the release. Record `process.exit` as the user's lever.

7. **Huge whole deadlines name the wrong number.** `1e300` and `Number.MAX_VALUE` are whole, so they pass the finite-and-whole check. `as i64` then saturates to 9223372036854775807. `deadline_millis` refuses that value, and 0095 says the message names the host's exact value. Fix: the addon refuses any whole value above 4,294,967,295,000, or below -1, with `usage` before the cast. The message names the JavaScript number. Pin the sentence in the R1-11 test.

8. **The budgets are grounded but tight for tests and package JavaScript.** Rust (650), scripts (170), and docs (240) have room. The package files start at 716 lines (the tag's 696 plus a 20-line `loader.js`) against a cap of 760. The abort race, UTF-16 conversion, surrogate checks, question spelling, and the `details` type must fit in the 44 lines left, after the annotate mapper and the hand-built `details` object come out. Tests start near 860 after the retirements, plus the 300-line conformance runner. About fifteen new proofs and `backend.mjs` then come close to 1,500. Fix: say whether `fork_child.mjs`, `fork_worker.mjs`, and the R3-25 child script count toward the twelve files and the line total. Either raise the test cap to about 1,700, or name what shrinks. The stop rule covers the rest.

9. **Small fixes.**
   - The "no `unsafe` token" step should match `\bunsafe\b`. The `reason` text in `src/node.rs` must not contain the word, or the step will match the permitted `allow` line.
   - The tag's `[profile.release] lto = true` must leave, because ADR 0047's profile check requires the root copy. Say so in "What moves from the tag".
   - The held-send deadline test depends on the engine enforcing a deadline during a blocking send. Cite the 0086 acceptance line that proves it.
   - Add one line under "Dependencies and second review": no license exception is needed, and name the licenses above.

### New findings

1. **The 256 KiB worker stack is unproven, and an overflow kills Node.** Decision 4 names the size with no measurement. Every gate test uses plain HTTP on loopback. So the TLS handshake, which the engine runs on the calling thread for a single send, never runs on that stack in any test. A Rust stack overflow aborts the whole Node process, and no panic guard catches it. Fix: spawn with Rust's default stack (2 MiB of reserved address space, touched only as used), or record a measurement that covers a TLS send and the largest `recognize` or `rank` payload.
2. **A settings plant would send to the built-in public address.** "Start from `Engine::builder()`" drops `THINKTHEN_BASE_URL`. The call then goes to the built-in address, which breaks "Nothing reaches a non-loopback address" and the repo's no-network rule for any run that includes the plant. Fix: prove the environment seeding with a setting that stays on loopback. For example, the child sets `THINKTHEN_CACHE` (or the model) through the environment and passes `baseUrl` naming the backend. It then asserts that the answer file lands in that folder. Under the plant the file lands elsewhere, and the address stays loopback.
3. **A missing `cache` contradicts itself.** Decision 3 says "a missing `cache` [maps] to `default_cache`", and also "a missing key keeps what the environment set". Calling `default_cache()` overrides a folder the environment seeded. The engines in the tests would then leave the per-test folder that shared rule 3 requires, and write to the user's real cache. Fix: a missing `cache` calls no setter. Map only `false` to `no_cache` and a string to `cache_at`.

## Spike amendment check (experiment 256)

ACCEPT

I read `74868576` as a diff from `5c5af23c`, experiment 256's `REPORT.md` (TypeScript findings 1 to 3), and main's `crates/thinkthen/src/engine/workers.rs`.

1. **A settled call releases its threadsafe function.** This is correct, and the gap was real. The handle's clone is shared, so an abort-only release kept Node alive after every normal result. Calling `detach()` when the promise settles, with a second run doing nothing, closes that gap. Firing the token of a call that has ended sends nothing. The new exit test has two children (a resolved call and a `deadline` rejection), a 500 ms bound, a kill at 3 s, and a plant. Together they make it provable and bounded.
2. **The premise is corrected.** `on_worker` sends every live attempt from an engine worker on the standard library's default stack. `request.rs:97` is the only live-send path, and it goes through `on_worker`. The binding's worker never hosts the handshake. The 2 MiB stack stays, and the measured 192 KiB debug and 48 KiB release figures back it.
3. **The `missing_docs` allow is fine.** `missing_docs` is `warn` at the root, so a local allow can lift it. The allow carries a reason, as `allow_attributes_without_reason` requires. ADR 0047 limits only `unsafe_code` to the FFI module.

Two nits, not blocking:
- "The spike observed both on the named machine" puts a machine name into a repo that will go public. Write "on the gate machine".
- "keeps a clone of the threadsafe function so `detach()` can abort it" is a trailing "so" clause. Split it into two sentences.

Both nits are applied in the commit that records this check.
