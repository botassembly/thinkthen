## Smallest proof and genuine open point

The existing `libraries/python/tests/conformance.py` can select `17-annotate-mixed` and `17-annotate-partial` through `THINKTHEN_CONFORMANCE_IDS`; those cases pin the null/failed distinction. `test_door.py::test_a_column_answers_as_its_list_does` and `test_annotate_on_a_frame_keeps_every_row_and_column` pin value equivalence and index/schema. `test_stopping.py::test_a_token_stops_a_held_single_send`, `test_ctrl_c_stops_a_held_batch_at_once` and `test_release.py::test_one_cancelled_call_releases_each_producer` pin the early stop and later cleanup. Add one small listener-backed batch table to those boundaries after B12a supplies the Rust planner, with exact request body/digest and three-row counts. No paid call, stress, full port rung or duplicate inventory is needed for design proof.

The real public choice is early Python cancellation: the current worker raises while requests remain held, whereas ADR 0089 promises final facts after Rust joins. Proposed ADR 0091 recommends an immediate exception carrying a completion receipt with eventual final facts and details. A frozen final `Cancelled.facts` at the immediate raise is impossible without waiting or lying about later replies. Design review should assess that tradeoff before source work; Ian can overturn the under-100-ms guarantee or the receipt spelling. A separate question is whether B12a's final API includes a many-text recognize batch for frames; until that source lands, this design preserves one call per text there and aggregates facts explicitly rather than asserting R7 is complete.

## Preparation lesson

The Python wrapper has no public lazy iterator even though its Rust calls can be lazy. The first call map could have mistaken one Python frame invocation for one Rust call; `each_named` currently loops over `recognize_with`. Inspect the concrete constructor and transport boundary before claiming one run's facts or batching. The outer worker's fast cancellation is a distinct API boundary from Rust's joined terminal error. Reuse 0209's source after landing and check both the inner frame schema and outer `Call` carrier; testing only the frame's cells would miss the new public result shape.
