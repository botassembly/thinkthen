## Forms and measurements that must stay separate

The historical [271 result](../../../../experiments/271-packed-requests/RESULTS.md) used 306 alphabetically ordered Beatles titles, an 18-positive Abbey Road key, cut 0.7, model `jev-1.13.0`, and a Python client's plain-lines evidence with a differently worded quoted question. Its all-in-one A306 arm had 276–278 right and 27–29 false yeses; the command's one-record baseline had 285 right and 16–17 false yeses. The [273 live review](2026-09-26-batching-and-recognize-evidence.md#14-a-fresh-reviews-live-batch-runs-local-experiment-273-2026-09-26) sent the *old planner* body via `annotate`: `{"records":[…]}` as evidence plus one quoted question per title. Its one 306-title request, three runs at cut 0.7, had 272–274 right and 32–34 false yeses. Its separate 20-title planted arm, two runs each, moved three wrong-title probabilities by 0.27–0.46 and one across 0.7. Neither figure measures today's plain decide/filter/rank batch.

The [275 retained experiment](../../../../experiments/275-ten-function-efficiency/README.md) measured the **quoted** form later chosen by [ADR 0055](../planning/adr/0055-decide-filter-and-rank-batches-send-each-record-once.md): evidence `Each question quotes the text it asks about.`, each title once in its own question, one request for the 306 titles. It used the same Abbey Road question/key/cut, a Python sender with model field `jev-latest` whose saved replies name `jev-1.13.0`, three same-body repeats and three shuffled orders. Its [saved score table](../../../../experiments/275-ten-function-efficiency/out/b4-score.txt) gives 283–287 right and 16–20 false yeses across six quoted runs, with 11,468 input tokens per run; its one-record control gives 286 right, 16 false yeses and 88,933 input tokens. The earlier `{"records":[…]}` form in that same table gives 266–277 right and 28–40 false yeses across six runs. These are measurements of those requests, corpus and model, not a general error bound or a fresh CLI default run. The 275 long-card, Ringo and release-year tasks likewise measure the quoted form; the Abbey Road numbers already address register 05's cited corpus, so another full B8/B9/B10 matrix is unnecessary.

Current [batch planner](../../crates/thinkthen/src/core/batch.rs) selects the fixed sentence for an ungrouped `Decide` with no context (`new_slice`) and quotes distinct records in questions (`batch/questions.rs`); a batch with one distinct record uses its old unquoted evidence (`built`). Filter and yes/no rank use the decide question route. The [0146 build](0146-build-command-batches-decide-filter-rank.md) and [batch body fixture](../../crates/thinkthen/src/core/batch/tests.rs) check that implementation. A no-context 306-title file in the retained order has no 1-in-4,096 content cut in the older simulation; the current planner also has size/profile, member and pause close rules, so actual command membership must be checked before attributing a provider figure to a particular default run. Matching the request *shape* does not establish matching model spelling, exact bytes, run timing, or answer probabilities.
