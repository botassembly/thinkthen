## What the build taught us

The scheduler's held flag served both admission and failure wording, so bounding only the CLI winner vector would leave completed batches unbounded behind a stalled earliest request. The private flow value split those responsibilities without changing streaming or uncut rank. A winner sink that drops an invalid row would otherwise hide the old end-only defect; one marker preserves it without keeping the full row. The acknowledged listener case detects the old unbounded dispatch behavior in a small fixture, while the source invariant carries the general bound. Strict Clippy forced a small helper, and the existing core ranking and listener utilities avoided another planner or fixture. The record-count bound should remain distinct from byte/RSS claims when reviewed and documented.
