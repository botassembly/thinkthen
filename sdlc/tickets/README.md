# tickets/

One file per ticket, numbered from 0001 in this repository. Take the next free number. A ticket authorizes work. It cites the specification sections it builds, and it lands through a worktree at `worktrees/thinkthen-NNNN` on branch `ticket/NNNN-slug`. Status is one of `ready`, `in progress`, `landed`. From 0120 on, a ticket carries the five-part Evidence section that `sdlc/README.md` describes.
