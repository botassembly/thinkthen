# 0342: relate asks a single-answer relation as one menu with none

Status: in progress. Plan: `sdlc/planning/cleanup-2026-09-30.md`, lane claude-1. Serves issue priorities rank 9 and the coordinator's relate precision default of 2026-09-30, which Ian can overturn.

## Outcome

A relate rule marked `"single": true` in a relate question file asks one `choice` per source name. The menu lists every allowed target and `none`. The top label makes the one edge when it is a target and reaches the cut, so `none` can leave a source without an edge. Every other rule asks its yes/no pairs as today. Each menu question is cached alone under ADR 0111's key. The relate page states relate's measured precision and points callers who need higher precision to `recognize --relation`. The relate host interrupt test no longer fails under load, and its issue is closed.
