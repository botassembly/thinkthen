# 0255: Give typed C calls their own facts

Status: fresh High design review accepted `d97f27350a9487c3e63e2438629b051f9b6e861f`. The coordinator approves implementation under the exact Lanes claim and the compatibility ruling in ADR 0101. Owner: Codex. No product or original-issue closure is claimed before code and installed proof pass review. [ADR 0101](../planning/adr/0101-typed-c-call-facts.md) proposes the ABI choice; the [preflight](../records/2026-09-28-c-facts-and-process-replay-preflight.md) pins the current gap.

## Outcome and retained contract

Ian ruled that library results carry facts on every call, without a setting or second call. Add call-owned immutable facts to new typed C entry points for decide, decide-many, recognize and relate, each with plain and `_opts` form. Preserve the existing eight exports, `thinkthen_answer` layout, six return codes, `thinkthen_free_string`, failure-only borrowed facts accessor, and typed value bytes. One call may make multiple actual sends; facts reflect the final call rather than the visible row count. The coordinator accepts the narrow compatibility exception for the existing eight bare exports under ADR 0101. New typed examples use the facts-returning forms. This does not assert that old compiled calls now return facts. The broader issue remains open for other surfaces, price, timing and request IDs even after this ticket.

## Evidence

- Starts from: Ticket 0230 and its accepted High review prove the separate C JSON door returns `{"value":...,"facts":...}`; `thinkthen_error_facts_json` borrows frozen facts only after a started failure. ADR 0089 fixes Rust call-scoped facts and rejects reconstructing them from process counters. The installed 0230 proof does not assert typed success facts.
- Keeps: `libraries/c/include/thinkthen.h` freezes the two-field answer and exported signatures for 0.1. Existing `libraries/c/tests/c/{opts,driver,threads}.c` and `examples/{functions,slide}.c` invoke typed names. Experimental direct consumers in experiment 273 Zig, experiment 294 Swift and experiment 295 Objective-C use typed symbols. Their retained packages are not automatically migrated or rebuilt by adding exports.
- Changes: `libraries/c/src/door.rs::decide` takes `Engine::details_with(...).into_value()` and drops `Call::facts`; `decide_many` consumes the Rust batch without reading final `Batch::facts`. `recognize` and `relate` already return `(JSON, Facts)`, but `ffi.rs` matches `(json, _facts)`. Add call-owned success facts for new typed symbols without changing the old symbols. `ffi.rs` has 497 nonblank lines against the 500-line source cap, so the coherent private unsafe edge needs an allowed `ffi.rs` child.
- Proof: `libraries/c/tests/door/main.rs` compiles a real C driver against the installed-style shared archive under AddressSanitizer and checks exported symbols against the header. A focused driver can count actual listener requests separately from packed logical answers and check allocation, failure and same-engine thread boundaries.
- Defers: The legacy-ABI exception, other surfaces, user-priced cost, server timing and request IDs remain separate decisions or outcomes. No package is advertised with the new exports until its installed archive and header are checked.

## Proposed change and exact claims after design acceptance

The [ADR](../planning/adr/0101-typed-c-call-facts.md) names eight `*_with_facts` exports. They retain each counterpart's argument order and add `char **facts_json, size_t *facts_len` after its result output. A new result and facts string are separately owned and freed through `thinkthen_free_string`. Before any raw slice, pointer addition or send, checked arithmetic bounds `count * sizeof(char *)`, `count * sizeof(size_t)`, `count * sizeof(thinkthen_answer)` and each text length to `PTRDIFF_MAX` / `isize::MAX`. Required null output slots and exact equal addresses among **all** output slots, including the length slots, refuse before a send. Callers remain responsible for valid aligned allocations and disjoint ranges; arbitrary invalid pointers or partial overlap cannot be safely detected. All fallible parsing, sending, batch completion, facts serialization and C-string conversion finish before any output slot changes. Failure leaves every output sentinel untouched, including the facts slots. A started failure still uses the existing borrowed error-facts accessor; an argument refusal has no facts. Missing backend usage omits token members instead of inventing zero. No JSON value or result schema changes.

After acceptance, request exact source claims on `libraries/c/include/thinkthen.h`, `libraries/c/src/{ffi,door,failures}.rs`, coherent private `libraries/c/src/ffi/typed_facts/ffi.rs`, `libraries/c/tests/c/typed_facts.c`, its registration in `libraries/c/tests/door/main.rs`, and derived `libraries/c/ratchet.json`. If a safe private helper belongs beside `door.rs`, name that child before editing. Existing `opts.c`, `threads.c`, and `nulls.c` are read-only proof unless the reviewed ABI requires a small necessary addition. The temporary marketing hold has expired for queue-owned pages after its two original branches landed. The implementation claim includes `libraries/c/README.md`, `libraries/c/DESIGN.md`, `libraries/c/examples/functions.c`, `libraries/c/examples/slide.c` and the C facts cell in `specification/settings.md`; required contract and example updates land with the code. Site remains with marketing. New examples should recommend `*_with_facts` and label old names compatibility forms; no existing consumer is forced to change or silently treated as receiving facts. Preserve current soname and current symbols while adding the new names. Rebuild each target package that claims the new symbols; do not infer support from source alone.

## Smallest outside-in proof

One new C driver through `tests/door/main.rs` calls all four plain and four options forms against fixed loopback replies. It checks exact result parity with old exports, required facts fields and optional token/model presence, independently counted listener arrivals, and `batch 1` for any one-record-per-send expectation. It frees each owned pointer. A compact refusal table covers null facts slots, every pairwise exact output-slot alias, each representability boundary, zero-count many, malformed input, a started backend failure and cancellation or deadline after a send. It compares all caller-owned sentinels before and after failure, tests `thinkthen_error_facts_json` only for started failures, and confirms the next typed call on the same engine plus a second caller thread does not borrow or overwrite another call's owned facts. Source inspection must show final facts are captured from `Call` before value conversion and from `Batch` after exhaustion but before row-count validation. The reviewed private guard must attach completed facts on an ordinary post-reply conversion defect and on an exceptional panic after that capture; a panic before completion keeps today's factless limit. No test-only panic hook is needed. The existing 0230 JSON-door installed proof, plain/options equality, error-table isolation and header-symbol check retain their own boundaries. Run relevant C policy, format, strict lint and measured ratchet checks; no provider, full suite or stress test is needed.

## Deferred limits and what the build should teach

The new forms cannot make an already compiled bare typed call return facts. The coordinator ruled on the narrow legacy exception in ADR 0101 after High review. Retain the explicit distinction between old bare compatibility calls and the new facts-returning typed API; never report a global all-call guarantee for old binaries. The alternate borrowed success accessor would avoid another provider request but would create a second C getter and mutable last-result lifetime; migration to `thinkthen_call` is available for flexible hosts but does not preserve the typed hot path. Do not add cost from an assumed vendor price, server timing, request IDs or a new result struct. Process-wide strict replay is register 103 and outside this ticket. During build, record whether `door.rs` can preserve final facts without duplicating its schedulers, whether all fallible publication work precedes the output commit, and which retained typed consumers require a later voluntary migration. A fresh High code/API review must inspect the actual installed header, allocator behavior and exact C driver outputs before landing.
