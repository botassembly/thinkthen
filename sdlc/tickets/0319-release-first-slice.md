# 0319: Build and prove the command-line release on this host

Status: ready. Plan: `sdlc/planning/cleanup-2026-09-30.md`, step 8. Issue: `sdlc/issues/2026-09-25-release-and-install-for-0-1.md`, items 1, 2, 11 and 13.

## Outcome

Two offline commands build this host's command-line release files and prove them the way a user meets them. The files are the static command archive, the first-run sample, and a `.sha256` beside each. The proof checks each checksum and the version line. It installs through `install.sh` from a loopback server into a clean prefix. It runs the README's no-key replay block against the unpacked release binary and sends nothing to any backend. Nothing is tagged, released, or published.
