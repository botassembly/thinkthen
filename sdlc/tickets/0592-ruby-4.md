# 0592 — ruby-4

Status: OPEN.

Milestone: 0.2

## Outcome

`gem install thinkthen` installs a working native gem on Ruby 3.4 and Ruby 4.0 on every shipped Ruby platform.

## Evidence

- Ian, 2026-10-15: "Definitely Ruby 4." Ruby 4.0 was released in December 2025.
- Starts from `ticket/0543-final`: `libraries/ruby/thinkthen.gemspec` sets the native gem to `>= 3.4, < 4` ("Built and tested on 3.4 only. 4.x is another ABI."), and Ruby 4.0 users get the fallback gem that raises `LoadError`. `libraries/ruby/Cargo.toml` pins `magnus = "=0.7.1"` and `rb-sys = "=0.9.130"`. `.github/workflows/release.yml` builds with Ruby 3.4.11. `libraries/ruby/tests/test_package.rb` pins the 3.4 range.
- 0543 depends on this ticket.

## Decisions

- PM decision, 2026-10-15: ship one native gem per platform that loads on Ruby 3.4 and 4.0, using the usual precompiled layout with one extension per Ruby minor version, and set `required_ruby_version` to `>= 3.4, < 4.1`. If magnus or rb-sys needs a newer pinned version for Ruby 4.0, take it.
- PM decision, 2026-10-15: the fallback gem message names both supported Ruby versions.

## Scope

- Changes: `libraries/ruby/Cargo.toml`, `libraries/ruby/thinkthen.gemspec`, `libraries/ruby/build.sh`, `libraries/ruby/check.sh`, `libraries/ruby/tests/test_package.rb`, `libraries/ruby/README.md`, `.github/workflows/release.yml`, `.github/workflows/install-check.yml`, `sdlc/scripts/install_check_channels.py`, `Cargo.lock` and `release-notes/0.2.0-known-gaps.md`.
- Checklist:
  1. Build the extension for Ruby 3.4 and 4.0 and package both in each platform gem.
  2. Run the installed Ruby check on 3.4 and 4.0; the routine profile runs 4.0, the release suite runs both.
  3. Update the package test's version pins and the fallback message.
- Keeps: the Ruby API and every result shape, unchanged on both versions.

## Proof

`libraries/ruby/check.sh` passes on Ruby 3.4.11 and the current Ruby 4.0 patch release, and the rehearsal's gem installs and runs on both.

## Defers

Nothing.
