## Design notes

- One home per page beats a shared include. The function page reads the same data files the reference page read, so the merge moves markup and deletes a page. It adds no data.
- `.grid` is the one card grid after slice B. The grid counts follow the CSS that exists. Three cards a row gives even rows at 3, 6 and 9, and two by two at 2 and 4. Any other count is a list.
- The paragraph check compares the text inside `main` after `label-tables.mjs` runs. Generated pages that share one sentence from a component, such as the global flags note, belong on `ALLOWED` with the component's name, or the sentence moves to one page and the rest link to it.
- A recipe's sample is small and replays. Its measured numbers come from the experiment's whole run and link there. The page states which is which.
