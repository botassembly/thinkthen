# 0273: Select and verify Linux x86 language runner tools

Status: design candidate for fresh independent High review. This ticket supports existing release consumer issues; it creates no new issue or public surface. [Preparation](../records/0273-linux-language-runner-preparation.md) compares main `f0f32c3c`, landed 0271 and accepted 0272. Implementation waits for accepted design and cleared 0272 shared workflow files. Ian holds all SQL/DataFrame work. This ticket authorizes static setup wiring and focused fixture checks only; actual runner setup, container, consumers and Actions need their later execution checkpoint.

## Outcome and boundary

Make the `ubuntu-24.04` x86 release jobs select deterministic inputs for the five added language families and fail before compilation or installed smoke when a required version, path or integrity check fails. Preserve 0271's manylinux source-wrapper route and exact family gates. Preserve 0272's one C archive, archived source, managed receipt handoff and package preflight. The existing Go/C++, Swift/Zig, PHP/Dart, legacy host setup and manual release controls remain in their current workflow. Other targets need no Ada, GNU Objective-C, COBOL or managed setup. Draft needs archive verification only and must not acquire SDKs.

The x86 build job needs .NET SDK 8.0.131, JDK 21.0.12.1, Kotlin 2.4.20 and Scala 3.9.0 before 0272's managed output step. Its manylinux source-wrapper phase needs none of the three 0271 host compilers. The x86 smoke job needs those four managed inputs plus GNATMAKE/GCC 13.3.0, the package whose selected `gprbuild` banner is Pro 18.0w, GNU Objective-C frontend/runtime, and the package whose selected `cobc` banner is GnuCOBOL 4.0-early-dev.0. Installed C#/JVM consumers need literal `/usr/bin/bwrap`; the checkout-owned backend still needs its existing ordinary host commands. Neither a package-version spelling difference nor an exit 77 is a passing tool probe.
