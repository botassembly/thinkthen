Retain the Flutter `publish_to: none` manifests and their local dependencies: the wrapper's `thinkthen_dart: path: ..`, and the example's Flutter and Dart dependencies at `path: ..` and `path: ../..`. Retain `ThinkThenFlutter`'s scalar `decide` facade, Dart `Door` reexport, separately supplied native library path and absence of a native download or Flutter plugin. The accepted 0260 Dart bulk proof covers that shared FFI conversion; this ticket tests the distinct real Flutter engine/app installation. No wrapper API, Dart runtime or native C source change is needed.
