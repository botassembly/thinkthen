# Quality measurement

Run `scripts/quality /path/to/thinkthen systemone` or select `openai`. Only run live by hand with authorization. The script inherits credentials without reading them. `--url` passes the command's backend address override, and `--data` selects a directory containing `cases.jsonl` and `comparison.json` for another labeled sample.

Each case names its function, command arguments, input text, expected items, source and license. Find matches exact character offsets. Recognize matches character offsets and kind after trimming trailing punctuation from the span, as the benchmark does. Relate matches the directed relation and both endpoint names. Counts are micro-averaged over each function; identical predictions are counted once, following the benchmark set metric. An unsure answer has no predicted items. A missing denominator prints zero. Failed commands or malformed rows stop the run; quality gaps do not.

The recorded comparison names its sample, metric, backend, source and comparability limit. It does not imply equivalent results when samples or tasks differ. Public benchmark texts may occur in model training.

The bundled sample holds all 48 `names-template` and all 40 `relations` cases from Beatles Bench, at commit `40e9384ccc33cd0c92a069ebe0708a4544f79d99`. Texts, identities and answer labels are unchanged; command arguments use this command's input format. Recognition uses the benchmark's exact offsets-and-kind rule, after trimming the span end past punctuation. The relation sample scores stated edges, with negatives retained. It does not compare these text answers with knowledge-only song-to-album scores.

Nine authored permit documents contain 100, 175 or 250 numbered positions. Two per size have a fixed answering line; one has no answer. They retain the fixed line content and answer positions named in the comparison record. Their recorded hit counts use a labeled-choice presentation; they establish no equivalent precision, recall or F1 baseline for the newline presentation.

The comparison preserves the frozen Beatles Bench report's scores. A null metric means unavailable; no score is invented from a different sample or from rounded figures. Recognition's published metrics are per kind, while the new totals are micro-averaged across kinds. Relation kinds come from this command's two rules, which is a setting difference from explicit recognition kinds in the recorded measurement. Only the System One model has recorded numbers. All live runs may differ because model versions and question wording affect answers.
