# question-file fixtures

`corpus.json` is the shared structural corpus. Each case names a question file, the verb it is asked under, and whether the file is valid. The parser test runs every case through `--plan` and expects the verdict; `self-test` runs the same cases through `question-file.schema.json` with Python's `jsonschema` and expects the same verdicts, once against the whole schema and once against the `decide`, `choose`, `tag`, `score`, or `relate` entry definition the case's verb names. Neither test replaces the other: the schema covers structure, and the parser's semantic checks finish the job, as `question-file.md` writes out.
