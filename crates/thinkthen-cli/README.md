# thinkthen command

This package installs the `thinkthen` command, including its local MCP stdio server. The command uses the public `thinkthen` Rust library.

```sh
cargo install thinkthen-cli
```

See the [command documentation](https://thinkthen.dev) for usage and the [MCP reference](https://github.com/botassembly/thinkthen/blob/main/specification/mcp.md) for the stdio interface.
