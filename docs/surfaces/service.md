# Where record text goes

By default, ThinkThen sends record text and questions to the TypeSafe System One service at `https://api.typesafe.ai/v1`, using `THINKTHEN_API_KEY`. `THINKTHEN_BASE_URL` changes only the System One address; an explicit client URL or command `--url` overrides the selected backend’s address. Selecting `openai` sends them to OpenAI and reads `OPENAI_API_KEY`; selecting `stub` sends nothing over the network and needs no key. `THINKTHEN_CA_FILE` supplies additional PEM certificate authorities alongside the operating system’s trust store. Proxy routing reads `ALL_PROXY`, `HTTPS_PROXY` and `HTTP_PROXY`, including their lowercase forms; `NO_PROXY` or `no_proxy` bypasses matching destinations. Local plain HTTP connections bypass proxies. Set these variables before creating a client, and select a service you trust with the records and questions.

A retried or manually resent POST can be processed and billed more than once, even if the first response was lost. ThinkThen does not provide an idempotency guarantee across attempts. Account for retries in request and cost budgets; disabling status retries does not undo a request already received by the service.
