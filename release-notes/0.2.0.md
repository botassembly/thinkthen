# ThinkThen 0.2.0

ThinkThen answers typed questions about text and images. It returns yes, no, not sure, a label, a number or a list. A failed call never looks like an answer.

`decide`, `choose` and `score` accept ordered JPEG and PNG images with optional text. Other functions refuse images before reading files or sending. Image questions need a supported backend and model. ThinkThen never resizes images behind your back.

`thinkthen mcp` exposes the ten functions to MCP clients over local stdio. It uses the same engine, backend and answer cache as the command. It creates no question files or configuration.

Saved questions add names, wording versions, input declarations and authored yes/no readings. Existing 0.1 question files work unchanged. Input declarations check values without changing them.

Each library function except C returns one result with `value`, `probability`, `results` and `facts`. C returns typed session packets. SQL plain calls return values. SQL `thinkthen_<function>_details` calls return typed rows. Results retain source locations, usage and observed model facts. Missing facts stay missing.

ThinkThen refuses 0.1 cache and recording files before sending. The message names the file and says to delete it. The database bytes and modification time stay unchanged. ThinkThen does not convert old stores. Save any answers you need before deleting those files.

The library is free and MIT licensed. Hosted models charge per token. Local models use your own computer.

Read the [known limits](https://github.com/botassembly/thinkthen/blob/v0.2.0/release-notes/0.2.0-known-gaps.md) before using images or MCP.
