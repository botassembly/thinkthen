# ThinkThen 0.2.0 known limits

Images work with `decide`, `choose` and `score` only. Liquid `d1`, Perplexity `pplx-decider-v1-27b` and explicitly declared supported local setups admit images. TypeSafe, OpenRouter, Ollama, the named MLX route and OpenAI Decisions refuse them. A supported route makes no claim about image accuracy.

Image size and decoded-input limits apply before sending. ThinkThen does not resize images to fit. Separate image files retain their source locations; paths never become model evidence.

MCP uses local stdio. Frame and attachment limits apply. An oversized output closes the connection after any work already performed. The server offers no question-writing, administration or business-routing tools.

Existing 0.1 question files work unchanged. Old cache and recording files refuse before sending. Keep a copy of old answers you need. ThinkThen does not migrate those files or support old call shapes.

Windows command builds are unsigned. Objective-C requires Apple Foundation and ARC. JVM requires JDK 22 or later.

Each engine uses one backend route. Your application or proxy supplies business routing and fallback policy. Live answers and probabilities can change between calls.
