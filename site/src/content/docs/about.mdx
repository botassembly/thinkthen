Ian Maurer builds ThinkThen at GenomOncology. The code is on [GitHub](https://github.com/botassembly/thinkthen) under the MIT license.

## Get help or report a bug

Ask questions and report bugs in [GitHub issues](https://github.com/botassembly/thinkthen/issues). Include:

- the output of `thinkthen --version`;
- the command you ran;
- the smallest text that shows the problem, with anything private removed.

[Troubleshooting](/reference/troubleshooting/) lists each error and its fix, so check it first.
