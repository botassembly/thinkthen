The Go SDK gives your code the ten functions as methods on a client; `tt.Answer` turns each result into a typed answer and an error, such as `true` or `false` from decide.

<Example id="lang-go" title="main.go" />

Install it (Go 1.23 or later, with cgo and a C compiler):

<InstallLine k="languages.go.install" />

Go turns cgo off on a machine with no C compiler. The build then stops with one error, `undefined: thinkthen_needs_cgo_set_CGO_ENABLED_1_and_install_a_C_compiler`. Install a C compiler and set `CGO_ENABLED=1`.

The client uses the key you set in the [Quickstart](/quickstart/). Call `client.Close()` when you're done with it.

## Build on Windows

cgo on Windows needs a 64-bit gcc, such as MinGW-w64, on `PATH`; it can't use the Visual Studio compiler. Save the program as `main.go` in a new folder, then run this in PowerShell in that folder:

<InstallLine k="languages.go.installWindows" lang="powershell" />

## When decide is not sure

Give decide a low and a high bar, and a text that falls between them is not sure. `tt.Answer` then returns `tt.ErrUnsure`, and the answer beside it is the zero value, `false`. Check the error before the answer, or not sure reads as a no. This message lands between the bars:

Send not sure to a person.

## When a call fails

Blank text fails at once, and nothing is sent. The error is a `*tt.Error`, and its `Code()` names the problem:

<Example id="sdk-go-failure" title="main.go" />

Any other failure, such as the service being down, comes back as a result whose `Status()` is `tt.Failed`, and `tt.Answer` returns its error. Match a family with `errors.Is(err, tt.ErrRecord)`, or one code with `errors.Is(err, tt.CodeRecordEmpty)`. A problem with the client itself, such as a wrong argument, comes back from `tt.New` or the call. [Troubleshooting](/reference/troubleshooting/) lists each code and its fix.

## The ten functions

Each example asks about the same support-inbox messages as the function pages. Each function has a one-message call, such as `client.Decide`, and an `All` call, such as `client.DecideAll`, that takes many messages and yields a result for each in a `range` loop. In an `All` loop, a failed message arrives as a result, and the loop's own error means the whole call failed.

### annotate

<details class="example-disclosure">

## The full API

`tt.Config` sets the batch size and retries, and `tt.JSON` and `tt.Records` build messages with ids. The [Go source](https://github.com/botassembly/thinkthen/tree/v0.2.0/sdk/go/thinkthen) lists every name.
