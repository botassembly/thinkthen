relate asks a bounded question about text and returns an answered, not-sure or failed result.

<Example id="functions/relate/command" />

<ExampleFile id="functions/relate/command" file="message.txt" />

```bash
message=$'Morgan works for Example Group.\nPlease refund my order.'

thinkthen relate \
  --text "$message" --rule person organization works_for --json |
  jq -r '
    if .status == "failed" then
      "failed: \(.error.code): \(.error.message)"
    else .answer[] |
      "\(.source.text) \(.relation) \(.target.text)"
    end'
```

A rule is the kind it starts from, then the kind it points to, then the relation name. Each relation has `source`, `target`, `relation`, `probability` and `either`. The result's `detail.names` holds every name found, including names in no relation. Without `--json`, relate prints the relations on one line, as `Morgan --works_for--> Example Group`, with tabs between them.
