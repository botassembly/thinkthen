decide answers a yes-or-no question about a piece of text. It says yes (`true`) or no (`false`), or, when you set a low and a high bar, not sure (`unsure`).

<Example id="decide-yes" />

Yes: the message asks for a refund.

## A no

<Example id="decide-no" />

No: the message asks about a delivery, not a refund.

## Not sure

Set a low bar and a high bar. decide says no below the low bar, yes at or above the high bar, and not sure in between.

<Example id="decide-unsure" />

Not sure: a double charge might be a refund request, or might not. Send not sure to a person. Never treat it as a no.

## See why

<details class="example-disclosure">
<summary>See why</summary>

`--json` prints the details. This `jq` keeps the two that explain the answer.

<Example id="decide-why" />

`probability` is the backend's estimate of yes. 0.7 falls between the bars of 0.2 and 0.8, so decide is not sure. [JSON output](/reference/json-output/) lists every field.

</details>

## Move the bar

<details class="example-disclosure">
<summary>Move the bar</summary>

With one bar, `--threshold`, decide always says yes or no. Raise the bar to 0.8 and the same text is a no, because 0.7 is below it.

<Example id="decide-bar" />

The default bar is 0.5. Lower it to say yes more often. Raise it to require a larger estimate for yes. See [interpreting probability](/reference/json-output/#interpreting-probability) for what these estimates mean.

</details>

## Use the answer in a script

<details class="example-disclosure">
<summary>Use the answer in a script</summary>

`--check` turns the answer into the exit code.

<Example id="decide-script" />

| Answer | Exit code with `--check` |
|---|---|
| `true` | 0 |
| `false` | 1 |
| `unsure` | 3 |

Without `--check`, decide exits 0 whenever it answers. [Exit codes](/command-line/exit-codes/) lists every code.

</details>

## Answer every row of a CSV file

<details class="example-disclosure">
<summary>Answer every row of a CSV file</summary>

<ExampleFile id="decide-csv" file="messages.csv" />

<Example id="decide-csv" />

`--column` names the column to read, and `--into` names the new answer column. A CSV file holds `TRUE` and `FALSE`, which Excel reads as yes and no. With no bars, the double charge is a yes. [File types](/command-line/file-types/) covers TSV, Excel and other files.

</details>
