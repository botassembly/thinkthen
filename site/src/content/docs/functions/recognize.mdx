recognize picks out every name in a piece of text that belongs to one of the kinds you list, whether there are several or none. It prints each name with its kind and where it sits in the text, separated by tabs.

<Example id="recognize-names" />

Two names: Morgan is a person, from character 0 to 6, and Example Group is an organization, from character 17 to 30.

## No names

<Example id="recognize-none" />

The message names no person and no organization, so the answer is empty.

## See why

<details class="example-disclosure">
<summary>See why</summary>

`--json` prints the details. This `jq` keeps each name, its kind and its chance.

<Example id="recognize-why" />

recognize keeps each name whose chance reaches the bar, 0.5 by default. [JSON output](/reference/json-output/) lists every field.

</details>

## Move the bar

<details class="example-disclosure">
<summary>Move the bar</summary>

Raise the bar to 0.99 and only Morgan is kept, because Example Group has 0.9702.

<Example id="recognize-bar" />

Lower the bar to catch more names. Raise it to keep only the clear ones.

</details>

## Recognize names in every row of a CSV file

<details class="example-disclosure">
<summary>Recognize names in every row of a CSV file</summary>

<Example id="recognize-into" />

`--column` names the column to read, and `--into` names the new answer column. Each cell lists its names as `name (kind)`, joined by `; `. [File types](/command-line/file-types/) covers TSV, Excel and other files.

</details>
