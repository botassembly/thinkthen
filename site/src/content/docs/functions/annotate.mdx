annotate asks several named questions about every line of its input at once. Each question uses one of the other functions, such as decide, choose or score, and annotate prints the line's number and then each answer as `name=answer`.

<Example id="functions/annotate/command" />

Each line holds three answers: whether the message asks for a refund, what it is about, and how urgent it is from 0 to 1. The questions live in a file. Each has a name, a function, and that function's question and choices or levels:

## Not sure

A question in the file takes the same bars as its function. Here the refund question gets a low bar of 0.2 and a high bar of 0.8:

<ExampleFile id="annotate-unsure" file="questions.json" />

<Example id="annotate-unsure" />

Line 3, the double charge, is not sure on refund, while its other answers stand. Send not sure to a person. Never treat it as a no.
