find reads a text line by line and prints the one line that answers your question. It prints nothing when no line answers, and says not sure (`unsure`) when the best line falls short of the bar.

<Example id="find-shell" />

<ExampleFile id="find-shell" file="message.txt" />

The second line asks for a refund, so find prints it.

## No line

<Example id="find-none" />

Nothing: the text says who Morgan works for, and asks for nothing.

## See why

<details class="example-disclosure">
<summary>See why</summary>

`--json` prints the details. This `jq` keeps the line and its chance.

<Example id="find-why" />

`probability` is the chance that this line answers the question. 0.77 reaches the bar of 0.5, so find prints the line. [JSON output](/reference/json-output/) lists every field, including where the line starts and ends.

</details>

## Move the bar


Raise the bar to 0.9 and find is not sure, because the line has 0.77.

<Example id="find-bar" />

Send not sure to a person. Never treat it as no line. The default bar is 0.5.


## Use the answer in a script

<details class="example-disclosure">
<summary>Use the answer in a script</summary>

`--check` turns the answer into the exit code, and the line still prints.

<Example id="find-script" />

| Answer | Exit code with `--check` |
|---|---|
| a line | 0 |
| no line | 1 |
| `unsure` | 3 |

Without `--check`, find exits 0 whenever it answers. [Exit codes](/command-line/exit-codes/) lists every code.

</details>

## Find a line in every row of a CSV file

<details class="example-disclosure">
<summary>Find a line in every row of a CSV file</summary>

Each cell can hold several lines, inside quotes.

<ExampleFile id="find-into" file="messages.csv" />

<Example id="find-into" />

`--column` names the column to read, and `--into` names the new answer column. A row with no line gets an empty cell. [File types](/command-line/file-types/) covers TSV, Excel and other files.

</details>
