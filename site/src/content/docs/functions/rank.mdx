rank returns results in rank order, retaining each original message.

<Example id="functions/rank/command" />

<ExampleFile id="functions/rank/command" file="messages.txt" />

rank puts many messages in order along your levels, highest first.

```bash
thinkthen rank 'How urgent is the request?' messages.txt \
  --level routine --level urgent --json |
  jq -r 'select(.status == "answered") | "\(.answer) \(.item)"'
```

`answer` is the rank, starting at 1, and `item` is your message. rank reads the whole file before it prints anything. `--top 5` ranks only the first five. A failed message comes after the ranked ones, with `status` set to `failed`. Without `--json`, rank prints your messages in rank order.
