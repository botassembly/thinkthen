rank places every line of its input on a scale of levels you name, from lowest to highest, and prints the lines from highest to lowest. `--top` keeps only the first few.

## Keep the top few

<Example id="rank-top" />

`--top 2` keeps the two most urgent lines and drops the rest.

## See why

<details class="example-disclosure">
<summary>See why</summary>

`--json` prints the details. This `jq` keeps three of them for each line.

<Example id="rank-why" />

`position` is the line's place in the input, `answer` is its rank, and `levels` holds the chance of each level, lowest first. Lines with equal scores keep their input order. [JSON output](/reference/json-output/) lists every field.

rank asks about each line as it reads. With `--top`, it holds only the best lines so far, plus any line that failed, in memory. Without `--top`, it holds every result until the input ends, because the last line can still change the order. Either way nothing prints before the input ends, and the plain output keeps each input line in a temporary file until then.

</details>

`--column` names the column to read, and `--into` names the new rank column. The rows stay in their order, each with its rank. With `--top`, a row outside the top gets an empty cell. [File types](/command-line/file-types/) covers TSV, Excel and other files.
