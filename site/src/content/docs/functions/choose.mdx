choose picks the one choice from your list that best fits a piece of text, and prints it. When even the best choice falls short of the bar, it says not sure (`unsure`).

<Example id="choose-pick" />

billing: the message asks for money back.

## Another choice

<Example id="choose-other" />

shipping: the message asks about a delivery.

## Not sure

choose picks the choice with the highest chance. If that chance is below the bar, it says not sure. The bar is 0.5 unless you set `--threshold`.

<Example id="choose-unsure" />

Not sure: the message is about billing and shipping at once, so neither choice reaches 0.9. Send not sure to a person. Never send it to a default choice.

## Move the bar

<details class="example-disclosure">
<summary>Move the bar</summary>

Raise the bar to 0.99 and the same clear message is not sure, because billing has 0.98.

<Example id="choose-bar" />

Lower the bar to accept a closer call. Raise it to answer only when one choice clearly wins.

</details>

## Use the answer in a script

<details class="example-disclosure">
<summary>Use the answer in a script</summary>

`--check` turns the answer into the exit code, and the choice still prints.

<Example id="choose-script" />

| Answer | Exit code with `--check` |
|---|---|
| a choice | 0 |
| `unsure` | 3 |

Without `--check`, choose exits 0 whenever it answers. [Exit codes](/command-line/exit-codes/) lists every code.

</details>
