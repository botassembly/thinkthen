Every function takes these options. Most can also come from an environment variable, and an option on the command line wins over its variable.

Each function's own options, such as `--threshold` for decide or `--choice` for choose, are on that function's page. `thinkthen FUNCTION --help` lists them all.

## On-or-off options

`--in-place`, `--details`, `--json`, `--quiet` and `--verbose` are off unless you give them. On the command line, the option alone turns it on, and `--json=false` turns it off. `--json`, `--quiet` and `--verbose` can also come from a variable, which takes `true` or `false`, such as `THINKTHEN_JSON=true`. `--in-place` and `--details` have no variable.

## How ThinkThen picks the input format

Without `--from`, a file ending in `.jsonl`, `.csv`, `.tsv` or `.xlsx` is read as that format. Anything else, standard input included, is read as one text for most functions, and as one text per line for filter, rank and annotate. [File types](/command-line/file-types/) shows each format.
