## 2. Set your key

ThinkThen sends each question to TypeSafe's System One service, which bills your TypeSafe account for each call. Get a key on the [TypeSafe keys page](https://console.typesafe.ai/keys), then set it in your shell:

```sh
export THINKTHEN_API_KEY='your key'
```

In Windows PowerShell:

```powershell
$env:THINKTHEN_API_KEY = 'your key'
```

To use OpenAI or your own server instead, see [Configuration](/configuration/).
