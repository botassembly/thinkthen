# PostgreSQL 0.1.2 migration fixture

`thinkthen--0.1.2.sql` is the actual schema generated by pgrx 0.17.0 from the MIT-licensed [published 0.1.2 source](https://proxy.golang.org/github.com/botassembly/thinkthen/@v/v0.1.2.zip), using PostgreSQL 16.14. It is not a hand-written substitute, and it makes no claim that a PostgreSQL binary package was released.

- Source ZIP SHA256: `b30a6c91e97ccf5ccc8c6a6c43db1c413ed5e741832d9a70971ba51b322bddef`.
- Generated SQL SHA256: `a080b263d57390b6d966df5812d232b115df84a42403cfab16f6db5e28a6869c`.
- Generation: `extensions/postgres/tests/published-schema.sh`, job `j39777`; the source lock was unchanged.

The migration check registers these exact declarations in an isolated PostgreSQL 18 test database while its C-language validator is temporarily suspended in a transaction. PostgreSQL's C validator ignores `check_function_bodies`, and the old PostgreSQL 16 binary cannot load into PostgreSQL 18. The transaction restores normal validation before testing the new extension. It never calls the old C functions or a paid backend; it tests extension ownership, dependent-view refusal, the documented drop/recreate, user-table preservation and dump restoration against the new extension.
